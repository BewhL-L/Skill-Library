## 🔧 MOC 维护与更新

### 新增笔记时
1. 将新笔记放入对应的文件夹
2. 在本 MOC 的对应子分类中添加该笔记的链接
3. 如果是新的子领域，在 MOC 中添加新的分类
4. 更新 MOC 中的文档数量统计
5. 在笔记中添加返回本 MOC 的链接
6. 更新 mindmap 导航体系总览

### 定期维护
- **每周**：检查新增笔记是否已加入对应 MOC
- **每月**：检查 MOC 中的链接是否有效（死链检测）
- **每季度**：重新审视 MOC 的分类结构，优化组织方式
- **每半年**：更新学习路线，结合技术发展调整学习重点

## 💡 MOC 与 Obsidian 功能结合

| 功能 | 用法 |
|------|------|
| **关系图谱** | MOC 页面是关系图谱中的核心节点，建议设置不同颜色组便于识别 |
| **反向链接** | 通过反向链接检查笔记是否都已加入 MOC，建议每篇笔记底部添加返回 MOC 的链接 |
| **标签** | MOC 页面带有 `MOC` 标签和领域标签，便于筛选和识别 |
| **模板** | 使用 Templater 插件管理 MOC 模板，新建 MOC 时直接使用保证结构一致 |
| **Dataview** | 可用 Dataview 动态生成 MOC 文档索引，自动更新 |

**推荐插件**：Dataview（动态索引）、Templater（模板管理）、Graph Analysis（图谱分析）、Waypoint（自动索引）
