# AI 方向论文分类与精读重点

> 供 paper-reader 精读论文时参考，按对应论文类型的精读重点执行。

---

## AI 方向论文分类

### 分类1：大语言模型（LLM）

**代表论文**：
- Attention Is All You Need（Transformer）
- GPT 系列（GPT-1/2/3/4）
- LLaMA 系列
- PaLM / Gemini 技术报告

**精读重点**：
| 部分 | 重点关注 |
|------|---------|
| 架构 | Transformer 结构改进（注意力机制、位置编码、归一化） |
| 训练 | 预训练目标、数据规模、训练策略（课程学习、混合精度） |
| 对齐 | RLHF、DPO、RLAIF 等对齐方法 |
| 能力 | 涌现能力、上下文学习、思维链、工具使用 |
| 效率 | 推理优化（KV Cache、量化、投机解码）、训练效率 |
| 评估 | 基准测试（MMLU、HumanEval、GSM8K）、评估方法 |

**关键问题**：
- 模型架构做了什么改进？为什么有效？
- 训练数据和训练策略有什么特点？
- 对齐方法的核心思想是什么？
- 模型在哪些任务上表现好/差？为什么？
- 有什么局限性和未来方向？

---

### 分类2：RAG / 检索增强生成

**代表论文**：
- Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks
- REALM
- RETRO
- Atlas
- Self-RAG

**精读重点**：
| 部分 | 重点关注 |
|------|---------|
| 检索器 | 检索模型（稠密/稀疏/混合）、索引构建、查询改写 |
| 生成器 | 生成模型、检索结果融合方式（拼接/注意力/交叉编码） |
| 切分策略 | Chunk 大小、切分方法（固定/语义/递归） |
| 重排序 | Reranker 模型、重排序策略 |
| 评估 | 检索评估（召回率/精确率/MRR）、生成评估（相关性/准确性/幻觉率） |
| 端到端 | 检索器和生成器联合训练、自适应检索 |

**关键问题**：
- 检索和生成如何结合？是拼接还是更深层的融合？
- 检索质量如何评估？用什么指标？
- 切分策略对效果有什么影响？
- 如何处理检索结果不相关的情况？
- 端到端训练 vs 模块化设计，各自的优劣？

---

### 分类3：Agent / 智能体

**代表论文**：
- ReAct: Synergizing Reasoning and Acting in Language Models
- Toolformer
- Reflexion
- Generative Agents（斯坦福小镇）
- AutoGPT / BabyAGI 相关论文

**精读重点**：
| 部分 | 重点关注 |
|------|---------|
| 规划 | 任务分解、计划生成、计划修正、反思机制 |
| 记忆 | 短期记忆（上下文）、长期记忆（向量数据库）、记忆检索和遗忘 |
| 工具使用 | 工具选择、工具调用、工具结果解析、多工具组合 |
| 推理 | 思维链、推理追踪、自我验证、错误恢复 |
| 多 Agent | 角色分工、通信机制、协作策略、冲突解决 |
| 评估 | 任务完成率、步骤效率、工具使用准确率、成本 |

**关键问题**：
- Agent 的核心架构是什么？规划-执行-反思循环如何设计？
- 记忆机制如何实现？短期和长期记忆如何配合？
- 工具使用如何保证准确性和可靠性？
- 多 Agent 协作的通信和协调机制是什么？
- Agent 的局限性是什么？如何评估 Agent 的能力？

---

### 分类4：多模态

**代表论文**：
- CLIP
- BLIP / BLIP-2
- GPT-4V（技术报告）
- LLaVA
- Flamingo

**精读重点**：
| 部分 | 重点关注 |
|------|---------|
| 视觉编码器 | ViT 结构、图像分辨率、视觉特征提取 |
| 对齐方式 | 对比学习（CLIP）、Q-Former（BLIP-2）、投影层 |
| 指令微调 | 多模态指令数据、训练策略、数据质量 |
| 能力 | 图文理解、视觉问答、图像生成、OCR、图表理解 |
| 评估 | 多模态基准（VQAv2、MMBench、SEED-Bench） |
| 效率 | 视觉 token 压缩、推理加速 |

**关键问题**：
- 视觉和语言如何对齐？用什么方法？
- 视觉编码器和语言模型如何连接？是端到端还是模块化？
- 指令微调数据如何构建？质量和数量哪个更重要？
- 模型在哪些多模态任务上表现好/差？
- 多模态模型的幻觉问题如何解决？

---

### 分类5：高效训练 / 推理优化

**代表论文**：
- LoRA: Low-Rank Adaptation
- QLoRA
- FlashAttention
- Speculative Decoding
- PagedAttention（vLLM）

**精读重点**：
| 部分 | 重点关注 |
|------|---------|
| 参数高效微调 | LoRA、Adapter、Prefix Tuning、Prompt Tuning |
| 量化 | 量化方法（GPTQ、AWQ、SmoothQuant）、量化感知训练 |
| 注意力优化 | FlashAttention、稀疏注意力、线性注意力 |
| 推理加速 | 投机解码、KV Cache 优化、连续批处理、PagedAttention |
| 分布式训练 | 数据并行、张量并行、流水线并行、ZeRO |
| 显存优化 | 梯度检查点、混合精度、Offloading |

**关键问题**：
- 优化方法的核心思想是什么？解决了什么瓶颈？
- 精度损失如何控制？在什么范围内可以接受？
- 加速比和显存节省的具体数据是多少？
- 适用于什么场景？有什么局限性？
- 实现复杂度如何？是否容易集成到现有系统？

## 论文精读八步法详解

### 第一步：标题与摘要（5分钟）
- 论文要解决什么问题？
- 核心方法是什么？
- 主要结果和贡献是什么？
- 判断是否值得精读

### 第二步：引言与相关工作（10分钟）
- 研究背景和动机
- 现有方法的局限性
- 本文的核心洞察和创新点
- 与相关工作的区别和联系

### 第三步：方法概述（15分钟）
- 整体架构图（画出或描述）
- 核心模块和数据流
- 关键公式和算法（理解含义，不纠结推导）
- 训练目标和损失函数

### 第四步：实验设计（10分钟）
- 数据集（规模、来源、划分）
- 评估指标（定义、计算方式）
- 基线方法（对比的是什么）
- 消融实验（验证哪些组件的作用）

### 第五步：结果分析（15分钟）
- 主要结果（核心表格/图）
- 与基线的对比（提升了多少，是否显著）
- 消融实验结果（每个组件的贡献）
- 案例分析（好的例子和坏的例子）

### 第六步：局限性与讨论（10分钟）
- 作者承认的局限性
- 你发现的问题或疑问
- 方法的适用范围和边界
- 可能的改进方向

### 第七步：与知识库关联（10分钟）
- 与已有笔记的关联（添加 [[]] 双链）
- 核心概念整理（生成概念笔记）
- 方法对比（与类似方法的对比表）
- 实践启发（对项目/学习的指导意义）

### 第八步：总结与输出（10分钟）
- 一句话总结论文核心贡献
- 3 个关键 takeaway
- 1 个可以应用到实践的点
- 生成论文精读笔记（存入知识库）
