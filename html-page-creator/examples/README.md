# 示例项目

本目录包含使用 html-page-creator Skill 创建的示例网页，展示不同类型网页的实现效果。

## 示例列表

| 示例 | 文件 | 类型 | 说明 |
|------|------|------|------|
| 个人作品集 | `portfolio-example.html` | 个人作品集 | 展示个人信息、项目作品、技术栈的作品集页面 |

## 如何使用示例

1. **直接查看**：在浏览器中打开HTML文件，查看渲染效果
2. **学习参考**：查看源代码，学习如何组合不同模块
3. **修改定制**：复制示例文件，根据自己的需求修改内容

## 示例特点

每个示例都展示了：
- 玻璃拟态设计风格
- 深色/浅色主题切换
- 响应式布局
- 滚动入场动画
- 滚动进度条
- 模块化内容组织

## 提交你的示例

如果你使用本Skill创建了优秀的网页，欢迎提交示例：

1. 将HTML文件放入本目录
2. 命名清晰，如 `learning-roadmap-example.html`
3. 在本README的示例列表中添加说明
4. 提交Pull Request
