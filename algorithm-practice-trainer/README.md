# 算法练习训练器

> 为算法刷题提供**分类训练、解题模板、复杂度分析、错题本管理、模拟面试**的全流程辅助。

---

## 功能特性

- **12 大题型分类训练**：数组/字符串/链表/栈队列/哈希/树/图/动态规划/回溯/贪心/二分/排序/位运算
- **标准解题模板**：每类题有标准解题模板，先背模板再灵活运用
- **复杂度分析速查**：常用数据结构和算法的时间/空间复杂度对照表
- **错题本管理**：错题按题型和错误类型分类，定期复习避免二错
- **算法模拟面试**：按真实面试流程进行，结束后生成评价报告和改进建议
- **刷题计划生成**：根据目标岗位、难度、时间生成个性化刷题计划

## 核心原则

1. **分类突破**：按题型分类训练，每类题先掌握模板再刷题，不盲目刷题
2. **模板优先**：每类题有标准解题模板，先背模板再灵活运用
3. **复杂度必算**：每道题必须分析时间复杂度和空间复杂度，不只是 AC
4. **错题复盘**：错题必须记录原因和正确思路，定期复习，不二错
5. **由易到难**：按 简单→中等→困难 递进，不跳级，基础题熟练后再上难度
