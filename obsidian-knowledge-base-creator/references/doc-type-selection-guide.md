# 文档类型选择指南

> 基于全栈工程知识库 12 大分类、64+ 篇实战文档、200+ 篇技术笔记的逆向分析提炼，帮助根据内容类型快速选择最合适的文档模板。

---

## 一、7 种文档类型总览

| 文档类型 | 模板文件 | 适用场景 | 核心结构 | 典型位置 |
|---------|---------|---------|---------|---------|
| 通用技术笔记 | `note-template.md` | 单个技术概念/工具/框架的深度讲解 | 概述→原理→实操→问题→拓展 五段式 | 各技术分类下 |
| 项目实战文档 | `project-template.md` | 完整项目的从零到一实现 | 概述→原理→分步实操→问题→进阶→验收 8大模块 | 99-项目实战 |
| MOC 内容地图 | `moc-template.md` | 某个分类/领域的内容索引和导航 | mindmap→学习路线→文档索引→快速导航→跨领域MOC | 各分类根目录 |
| 学习路线 | `learning-path-template.md` | 某个领域的系统化学习路径规划 | 四阶段→核心技能→项目实践→验收标准 | 00-综合导航 |
| 面试题汇总 | `interview-template.md` | 某个领域的高频面试题集合 | 分类总览→题目(考察点/解答/扩展)→面试技巧 | 09-面试与求职 |
| 资源汇总 | `resource-template.md` | 某个领域的精选资源和工具集合 | 分类总览→资源详情→对比表→学习路径→速查表 | 98-资源与工具 |
| 枢纽索引 | `hub-template.md` | 某个子领域的核心概念入口和索引 | 知识体系→概念索引→学习路径→实战→常见问题 | 各分类下子领域 |

## 二、选择决策树

```
开始
  │
  ├─ 内容是单个技术概念？
  │   └─ 是 → 通用技术笔记 (note-template.md)
  │
  ├─ 内容是完整项目实现？
  │   └─ 是 → 项目实战文档 (project-template.md)
  │
  ├─ 内容是某个分类的所有文档索引？
  │   └─ 是 → MOC 内容地图 (moc-template.md)
  │
  ├─ 内容是学习路径规划？
  │   └─ 是 → 学习路线 (learning-path-template.md)
  │
  ├─ 内容是面试题集合？
  │   └─ 是 → 面试题汇总 (interview-template.md)
  │
  ├─ 内容是资源/工具汇总？
  │   └─ 是 → 资源汇总 (resource-template.md)
  │
  └─ 内容是某个子领域的核心概念入口？
      └─ 是 → 枢纽索引 (hub-template.md)
```

## 三、各文档类型详细说明

### 1. 通用技术笔记（note-template.md）

**适用场景**：
- 讲解某个技术概念（如"Vue3响应式原理"、"JVM垃圾回收"）
- 介绍某个工具/库的使用（如"Redis实战"、"Docker入门"）
- 分析某个原理/机制（如"TCP三次握手"、"React Fiber架构"）

**核心结构**：
1. 概述（定义、作用、解决什么问题）
2. 原理（底层机制、核心逻辑、架构设计）
3. 实操（安装配置、代码示例、最佳实践）
4. 问题（常见错误、排查方案、性能调优）
5. 拓展（进阶用法、生态工具、相关概念）

**规模参考**：500-2000行，3-15KB

**何时不用**：
- 内容是完整项目 → 用项目实战模板
- 内容是多个概念的索引 → 用MOC或枢纽模板
- 内容是面试题 → 用面试题模板

---

### 2. 项目实战文档（project-template.md）

**适用场景**：
- 从零构建一个完整项目（如"FastAPI+RAG知识库问答"）
- 包含完整可运行代码的项目教程
- 覆盖从需求分析到部署上线的全流程

**核心结构**：
1. 项目概述（目标、技术栈表、系统架构图）
2. 核心原理（工作流程、关键设计决策）
3. 分步实操（6-10步，每步完整可运行代码）
4. 常见问题与排查（问题→原因→解决方案表+性能优化）
5. 进阶与最佳实践（生产环境增强+部署方案）
6. 关联笔记
7. 项目验收标准（5条可量化）

**规模参考**：
- 🟢入门：200-400行，3-5个代码文件
- 🟡进阶：400-800行，6-10个代码文件
- 🔴高级：800-1500行，10-15个代码文件
- ⚫专家：1500-2500行，15-20个代码文件

**何时不用**：
- 只讲概念不写代码 → 用通用技术笔记
- 只是项目列表/索引 → 用MOC

---

### 3. MOC 内容地图（moc-template.md）

**适用场景**：
- 某个顶级分类的内容索引（如"01-前端开发"的MOC）
- 某个大领域的导航入口（如"AI与效率工具"的MOC）
- 知识库的综合导航首页

**核心结构**：
1. Frontmatter（hub: true）
2. 内容地图说明
3. Mermaid mindmap 导航体系总览
4. 四阶段学习路线表格
5. 文档索引（按子分类表格，难度标识）
6. 快速导航（按用户场景：新手/找技术点/做项目/查进度）
7. 跨领域MOC导航表格
8. MOC维护与更新流程
9. MOC与Obsidian功能结合
10. 底部导航

**规模参考**：200-400行，10-20KB

**何时不用**：
- 只是某个子领域的概念索引 → 用枢纽模板
- 内容是学习路径规划 → 用学习路线模板

---

### 4. 学习路线（learning-path-template.md）

**适用场景**：
- 某个领域的系统化学习路径规划
- 从入门到专家的分阶段学习指南
- 包含时间规划、验收标准、项目练习的路线图

**核心结构**：
1. 路线总览（学习目标、预计时间、适合人群）
2. 四阶段学习规划（入门→进阶→高级→专家）
3. 每阶段详细内容（核心技能、知识点清单、项目练习、验收标准）
4. 学习资源推荐
5. 常见问题与建议
6. 进度追踪表

**规模参考**：300-600行，10-20KB

---

### 5. 面试题汇总（interview-template.md）

**适用场景**：
- 某个领域的高频面试题集合
- 面试准备的刷题资料
- 包含考察点分析、标准解答、扩展问题的面试指南

**核心结构**：
1. 题目分类总览（分类、题数、难度、核心考点）
2. 每道题（难度、考察点、出现频率、题目、解答、扩展问题、相关知识点）
3. 面试技巧总结（答题框架、高频考点优先级、注意事项）
4. 关联笔记

**规模参考**：500-2000行，15-50KB（取决于题数）

**何时不用**：
- 只是单个知识点的深度讲解 → 用通用技术笔记
- 内容是面试经验/技巧分享 → 用通用技术笔记

---

### 6. 资源汇总（resource-template.md）

**适用场景**：
- 某个领域的精选资源和工具集合
- 官方文档、教程、书籍、课程、工具的汇总
- 包含推荐理由、使用场景、对比表格的资源指南

**核心结构**：
1. 资源分类总览（分类、数量、代表资源、适合人群）
2. 每个资源详情（类型、难度、语言、免费/付费、链接、推荐理由、使用场景、注意事项）
3. 资源对比表（多维度对比+选型建议）
4. 学习路径推荐（按阶段推荐资源+学习顺序）
5. 工具速查表（常用命令/操作）
6. 关联笔记

**规模参考**：300-800行，10-25KB

---

### 7. 枢纽索引（hub-template.md）

**适用场景**：
- 某个子领域的核心概念入口（如"Java并发"枢纽、"RAG"枢纽）
- 连接该子领域所有核心概念的索引页
- 比MOC更聚焦、比单篇笔记更全面的中间层

**核心结构**：
1. Frontmatter（hub: true）
2. 知识体系总览（Mermaid mindmap）
3. 核心概念索引（按子分类表格，含难度、一句话说明、链接）
4. 学习路径（推荐顺序+按阶段推荐）
5. 实战与项目
6. 常见问题速查
7. 相关资源
8. 跨领域关联
9. 底部导航

**规模参考**：150-400行，8-15KB

**与MOC的区别**：
- MOC：覆盖整个顶级分类，文档数多（30-100篇），是分类入口
- 枢纽：覆盖某个子领域，文档数少（10-30篇），是子领域入口

## 四、混合使用场景

### 场景1：新建一个技术领域的完整知识体系

```
1. 创建该领域的 MOC（moc-template.md）→ 分类入口
2. 创建学习路线（learning-path-template.md）→ 路径规划
3. 创建各子领域的枢纽（hub-template.md）→ 子领域入口
4. 批量创建通用技术笔记（note-template.md）→ 知识点
5. 创建2-3个项目实战（project-template.md）→ 实战
6. 创建面试题汇总（interview-template.md）→ 面试
7. 创建资源汇总（resource-template.md）→ 资源
```

### 场景2：为现有知识库补充某个子领域

```
1. 创建该子领域的枢纽（hub-template.md）
2. 批量创建该子领域的通用技术笔记
3. 更新上级分类的 MOC，添加该子领域的索引
4. 创建1个相关项目实战
```

### 场景3：准备面试

```
1. 创建目标领域的面试题汇总（interview-template.md）
2. 每道题关联到对应的通用技术笔记
3. 创建面试技巧/经验分享的通用技术笔记
4. 更新 MOC 的快速导航，添加"面试准备"场景
```
