# API 参考

> **注意**：本 Skill 为**纯文档型 Skill**，无可执行代码和 API 接口。本文档说明 Skill 的"接口"——即输入输出规范和触发方式。

---

## 触发接口

### 输入

用户的自然语言请求，满足以下任意条件即触发：

- "我想做一个 XX 项目"
- "帮我规划/搭建一个 XX"
- "从零开始做 XX"
- "帮我生成 XX"
- "我要完成 XX，帮我"
- 任何描述了"需要多步骤、多产物才能完成的目标"的请求

### 输出

1. **项目产物**：直接写入用户指定的项目目录
2. **《项目全景总结与行动指南.md》**：放在项目根目录
3. **自检报告**：12 维度检查结果（可用 `scripts/check_baseline.py` 跑其中 7 项）
4. **Git 仓库**：初始化并提交

## check_baseline.py — 工程底座自检

| 参数 | 说明 |
|---|---|
| `--root` | 项目根（默认 `.`） |
| `--skip` | 跳过检查，逗号分隔（`schema,index,ci,docs,private,defaults,deadconfig`） |
| `--strict` | 警告也视为失败（默认只有 error 阻断） |
| `--json` | JSON 输出 |

输出三级：`ERROR`（退出码 1）/ `WARN`（默认不阻断）/ `OK`（含信息项）。

退出码：`0` 通过（或仅有警告）；`1` 存在 error 或 `--strict` 下有警告。
