# Frontend Audit Loop — 网页改造多轮自检收敛

一句话：**固定维度、轮次迭代、每轮必回归、收敛即止**。产出一轮「通过项 + 已修复项」清单，终轮给出带依据的"无需进一步优化"结论。

## 核心原则

1. **探针优先**：能断言的不靠截图，能读 DOM 的不靠读图——人眼是最后一道而非唯一防线
2. **根因修复**：先定位根因再动手，拒绝补丁叠补丁；修复后必须读回编辑区段
3. **回归纪律**：任何修复后全量重跑既有断言，通过才进下一轮
4. **有限迭代**：出现零发现轮即收敛，收益递减的打磨本身就是回归风险

## 适用场景与触发条件

- 网页/前端改造（视觉升级、重构、动效新增）完成后的成品质检
- 用户要求"全面检查/体检/自检/优化到没有问题"
- 交付前需要防回归验证（多主题 × 多视口 × 交互链）
- 不适用：从零新写页面（应先走设计流程再进场自检）、纯后端/数据校验

## 标准执行流程

1. **建立检查矩阵**：五个维度固定不变，逐轮覆盖——
   ① 设计一致性（令牌统一、组件语言、死代码）
   ② 视觉美学（配色层级、间距节奏、视觉焦点）
   ③ 排版与响应式（断点行为、多视口、溢出）
   ④ 功能与交互（渲染正确性、持久化、焦点、边界）
   ⑤ 动效与性能（合成属性、降级覆盖、常驻开销）
2. **每轮三步**：检查（静态扫描 + 截图走查 + 探针断言）→ 修复（根因级）→ 回归（全量断言重跑，防修复引入新问题）
3. **轮次产出**：每轮输出「通过项 / 已修复项」两栏清单
4. **收敛判定**：出现一整轮零发现，且上一轮修复的回归全部通过 → 再做一次终轮复扫确认 → 输出"无需进一步优化"结论并列出依据
5. **收尾**：更新工作日志；若执行过团队协作，关闭全部 teammates 后删除团队

详见 [references/audit-rounds.md](references/audit-rounds.md)（各维度检查项清单）与 [references/verification-toolkit.md](references/verification-toolkit.md)（探针/断言/截图的可运行模板与工具坑点）。

## 关键决策依据

- **单干 vs 组队**：改动面 ≤2 个维度且无对立评审需求 → 单干直改；≥3 个维度或需要"视觉方向 / 体验根因 / 工程落地"三方视角 → 建团队（architect → ux → engineer），主控只做编排与**独立交叉验收**。编排模板见 [references/team-orchestration.md](references/team-orchestration.md)。
- **修复 vs 记录**：纯样式/令牌/死代码 → 直接修；涉及交互语义变化（删功能、改行为）→ 列入清单征询后再动。
- **何时停止迭代**：某轮零发现即停，不追求"感觉还能更好"——收益递减且每轮改动本身就是回归风险。
- **验证手段优先级**（由廉到贵）：静态令牌扫描 → 截图走查 → headless 探针断言 → jsdom 交互冒烟。能断言的不靠截图，能截图的不靠人眼描述。

## 常见坑点与规避

| 坑 | 规避 |
|---|---|
| headless 浏览器把 CSS 视口钳到最小值（如请求 390 实际 492），小屏截图"裁切"是伪影 | 用 **iframe 法**（外窗任意宽，iframe 设真实目标宽 + `--allow-file-access-from-files`），探针读 iframe 内部 clientWidth 佐证 |
| 截图时机早于页面定时器，探针文本空白 | 用 `--virtual-time-budget` + `--dump-dom` 直接读 DOM 文本，不靠截图读数 |
| SVG 元素的 `className` 是 SVGAnimatedString，探针取值报 `[object object]` | 取 `.baseVal` |
| `input::after` 勾号在 Firefox 不渲染 | 表单控件勾号用背景图（data-URI 走 CSS 变量分主题换色），不用伪元素 |
| 手动主题块（`[data-theme=…]`）是媒体查询块的**不完整副本**，系统主题 × 手动主题交叉时令牌泄漏 | 用 diff 脚本对比各主题块声明集合，要求完全一致（见 verification-toolkit） |
| jsdom 点击不聚焦，焦点恢复断言"假失败" | 断言前显式 `.focus()` 模拟真实浏览器；先甄别伪影再怀疑产品 bug |
| 编辑工具替换时把相邻行一起吞掉（CSS 断行丢失） | 修复后立即读回目标区段确认，不等轮末统一验 |
| 无限打磨不收敛 | 固定维度清单，零发现即收敛；新想法记录待办不进本轮 |

## 质量验收标准（全部满足才算收敛）

1. 交互冒烟断言 0 失败（渲染数量、持久化、焦点、边界至少各 1 条）
2. 最窄目标视口探针 `scrollWidth === clientWidth`（文档级零溢出），越界元素均可归因于有意溢出容器
3. 双主题 × 多视口截图走查无布局破损，主题块令牌集合 diff 一致
4. 常驻动画只动 `transform/opacity`（例外需文档化理由，如单元素 box-shadow）
5. `prefers-reduced-motion` / `reduced-transparency` / `contrast: more` 三套降级均有覆盖
6. 终轮为"零发现轮"，且结论附依据（上一轮修复项的回归证据）
