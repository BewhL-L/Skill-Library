# code-practice-generator 常见问题解答

> 使用代码实践生成器时的常见问题和解答。

---

## Q1：生成的项目能直接运行吗？需要我自己改什么？

**A**：生成的项目应该能直接运行，但需要注意：
1. **环境依赖**：确保已安装对应技术栈的运行环境（Node.js 18+、JDK 17+、Python 3.10+ 等）
2. **依赖安装**：首次运行需要执行依赖安装命令（npm install、mvn install、pip install -r requirements.txt）
3. **外部服务**：如果项目依赖 MySQL/Redis 等外部服务，需要先启动这些服务
4. **配置修改**：数据库连接、API Key 等配置需要根据本地环境修改

生成的 README 中会包含完整的环境要求和运行步骤，按步骤操作即可。

---

## Q2：练习题的答案在哪里？会不会和题目混在一起？

**A**：答案和题目是分离的：
- **题目**：在 `src/exercise/` 或 `exercises/` 目录下，只有题目描述和空的实现框架
- **答案**：在 `solutions/` 目录下，按难度分 `basic/`、`advanced/`、`challenge/` 子目录
- **解析**：每个答案文件顶部有详细的思路分析、关键步骤、常见错误、复杂度分析

建议先自己做题，做完再对照答案和解析。如果卡住了，可以先看解析的思路部分，再尝试自己实现。

---

## Q3：可以只生成练习题，不生成完整项目吗？

**A**：可以。有两种方式：
1. **单题练习**：描述具体题目要求，生成单道题的题目、答案、解析
2. **题集练习**：描述主题和数量，生成 N 道题的题集（每题有题目+答案+解析）

单题/题集练习不需要完整项目结构，只输出题目和答案即可。但完整项目的优势是可以直接运行验证，建议核心概念用完整项目，辅助练习用单题/题集。

---

## Q4：生成的项目代码质量如何？符合生产规范吗？

**A**：生成的项目代码遵循以下规范：
1. **命名规范**：变量、函数、类名符合对应语言的命名规范（camelCase/PascalCase/snake_case）
2. **代码注释**：关键逻辑有注释，复杂算法有思路说明
3. **错误处理**：有基本的异常捕获和错误提示
4. **目录结构**：符合对应技术栈的标准项目结构
5. **依赖版本**：使用稳定版本，不使用已废弃的 API

但这是学习项目，不是生产项目。生产项目还需要：完整的测试覆盖、CI/CD 流水线、安全审计、性能优化、监控告警等。学习项目重点是理解概念，生产规范是参考。

## Q5：练习题的难度是怎么划分的？

**A**：三个难度级别的定义：
- **基础题（3道）**：掌握基本用法，能照着写出来。通常是修改现有代码、实现简单功能、填空。每道 10-15 分钟。
- **进阶题（2道）**：理解底层机制，能灵活运用。通常是实现完整功能、排查 Bug、性能优化。每道 30-45 分钟。
- **挑战题（1道）**：综合运用，达到生产环境水平。通常是设计完整方案、实现复杂功能、源码级扩展。每道 60-90 分钟。

如果觉得基础题太简单，可以直接从进阶题开始。如果挑战题太难，可以先看答案的思路，再尝试自己实现。

## Q6：生成的项目如何与知识库笔记联动？

**A**：通过以下方式联动：
1. **README 双链**：README 中提到的技术概念都添加 `[[]]` 双链，如 `[[Vue3响应式]]`、`[[Proxy]]`
2. **代码注释**：代码中的关键概念标注对应的知识库笔记
3. **笔记引用**：在知识库笔记的「实操」模块添加项目引用链接
4. **完成标记**：项目完成后，可以在笔记中添加"已完成实践项目"标记

这样做项目的过程也是复习笔记的过程，项目完成后知识点也巩固了。

## Q7：可以生成指定技术栈的项目吗？比如我只想练 Python + FastAPI

**A**：当然可以。支持的技术栈：
1. **Java / Spring Boot**：Maven 项目，包含 Controller/Service/Entity 分层
2. **Vue3 + TypeScript**：Vite 项目，包含组件/组合式函数/类型定义
3. **Python / FastAPI**：包含路由/模型/服务分层，支持异步
4. **AI / LangChain**：包含 Chain/Agent/Retriever，支持 LLM 调用
5. **混合技术栈**：如 Vue3 + Spring Boot 全栈项目、Python + LangChain AI 应用

在需求描述中明确技术栈即可，如"生成一个 Python + FastAPI 的异步处理练习项目"。
