# 人生指导手册生成器（Career & Life Guidance）

> 为普通背景个体生成"从决策到站稳脚跟"的全周期人生与职业指导手册。把"普通背景个体如何靠能力而非标签改变命运"这件事，做成一份**有温度、可执行、按优先级组织、贴合真实身份**的书籍级手册。

## ✨ 核心理念

- **不做空泛的宏观环境分析**，只写"这个人明天起床后具体该做什么"
- **以用户真实身份为锚**，按人生时间线组织，每个建议回答三件事——为什么重要 + 具体怎么做 + 不做的后果
- **成品标杆是书籍级手册**：完整版10-20万字、六篇数十章、上百张表格与数十张流程图
- **用户不是在读报告**，而是在听一个走过这条路的前辈，坐在对面跟他说实在话

## 🎯 适用人群

- 普通一本/二本/大专学历者
- 零基础/跨专业/转行者
- 在校学生（大三大四面临就业选择）
- 工作3-5年遇到瓶颈者
- 35岁危机应对者
- 任何需要"从决策到站稳脚跟"全周期指导的人

## 📚 核心能力

| 能力 | 说明 |
|------|------|
| 🎯 **职业方向选择** | A还是B赛道？多维度对比取证，三情景推演，给出贴合身份的推荐 |
| 📖 **学习路线规划** | 从零基础到入职的完整时间线，每日/每周/每月学习计划，资源推荐 |
| 🛠️ **项目实战指导** | 从易到难的项目设计，完整实现指南，工程化规范，简历包装技巧 |
| 💼 **求职冲刺策略** | 简历优化、面试题库、薪资谈判、签约避坑、入职适应 |
| 📈 **中长期发展** | 晋升路径、跳槽策略、地区选择、35岁危机应对、副业规划 |
| 🧘 **支撑维度** | 身体健康、心理韧性、理财规划、社保公积金、个人品牌、人脉建设、英语能力 |
| 🔄 **多轮迭代** | 手册通常迭代3-5版，每轮有明确的深化方向和验收标准 |
| 📝 **标准化输出** | Obsidian双链、流程图、Frontmatter、完整文档套件，可直接导入知识库 |

## 📁 产出结构（六篇人生时间线）

```
人生指导手册/
├── 写在前面（致读者的信 + 使用指南）
├── 第一篇：决策与方向（我是谁、我要去哪、为什么是这条路）
├── 第二篇：学习与成长（从零到能做项目的完整路线）
├── 第三篇：项目与实战（3-5个从易到难的完整项目，占全书25%-35%）
├── 第四篇：求职与入职（简历、面试、谈薪、入职前100天）
├── 第五篇：站稳与发展（晋升、跳槽、副业、35岁、10年规划）
├── 第六篇：支撑与风险（身体/心理/理财/社保/品牌/人脉/英语 + 风险预案）
├── 收尾套件（资源清单、工具推荐、书单、模板、FAQ）
└── 文档信息（版本、更新日志、使用说明）
```

## 🚀 快速开始

### 使用方式

本Skill为AI Agent设计，无需手动运行命令。在对话中描述你的情况和需求即可：

```
"我是普通一本计算机专业大三学生，帮我做一份完整的职业规划"
"我是机械专业毕业2年，想转行做程序员，零基础"
"我35岁，做后端5年，担心35岁危机，帮我规划未来"
```

### 工作流程（8步）

1. **身份校准** - 锁定8个身份字段（学历/专业/年龄/经验/城市/目标/约束/偏好）
2. **赛道选择与取证** - 多方向对比，行业取证，三情景推演
3. **搭建全书骨架** - 六篇结构，固定套件，章节规划
4. **填充学习路线** - 时间线、资源、方法、心态
5. **填充项目实战** - 3-5个项目，完整实现指南（重中之重）
6. **填充求职与长期发展** - 简历、面试、晋升、跳槽、35岁
7. **补齐支撑维度与风险预案** - 身体/心理/理财/社保/品牌/人脉/英语
8. **标准化输出与校验** - Obsidian格式、流程图、校验清单

## 📊 成品标准

### 量级标准（按版本递进）

| 版本 | 字数 | 章节 | 表格 | 流程图 | 适用场景 |
|------|------|------|------|--------|---------|
| 简版 | 2-5万字 | 6篇15章 | 20+ | 5+ | 快速决策参考 |
| 标准版 | 5-10万字 | 6篇30章 | 50+ | 15+ | 完整执行手册 |
| 完整版 | 10-20万字 | 6篇50+章 | 100+ | 30+ | 书籍级人生指南 |

### 密度指标（完整版下限）

- 每1000字至少1个可执行动作
- 每章至少1张表格或流程图
- 每个建议包含"为什么+怎么做+不做后果"
- 项目篇占全书25%-35%篇幅
- 至少3个从易到难的完整项目
