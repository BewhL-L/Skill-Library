# 五维轮次检查清单

每轮按维度顺序过一遍；勾选项即"通过项"，发现的问题进"已修复项"。清单是超集，按项目实际裁剪，但**裁剪后轮间保持一致**（否则收敛判定失真）。

## 维度① 设计一致性
- [ ] 颜色零散硬编码：grep 十六进制色 / rgba，全部收敛为 `--` 令牌（辉光类可白名单，需注释理由）
- [ ] 同一语义在深浅色下成对定义（前景绿/填充绿/描边绿分立，不能共用一个值）
- [ ] 手动主题块与媒体查询块的**声明集合 diff 为空**（防交叉泄漏，最高频暗雷）
- [ ] 死代码：被替换组件遗留的选择器、永不在匹配断点内的规则
- [ ] 组件语言一致：圆角/描边/内边距走同一组令牌，无同类异值

## 维度② 视觉美学
- [ ] 信息层级：一屏只有一个主视觉焦点，装饰层不与内容抢对比度
- [ ] 间距节奏：间距值来自间距标尺（如 4/8/16/20/32…），无 `.5px` 碎值
- [ ] 字号系统：字号有层级（body/小字/说明/数字），同层级同字号
- [ ] 装饰动效峰值不透明度受限，不干扰正文可读性
- [ ] 深浅两主题分别截图走查，白压白 / 黑压黑不可见

## 维度③ 排版规范与响应式
- [ ] 最窄目标视口（常见 360/390）探针 `scrollWidth === clientWidth`
- [ ] 越界元素逐一归因：必须位于有意溢出容器（横滑条、fixed 背景层）内
- [ ] 栅格断点自洽：跨列/不等宽的启用断点 = 最小可容纳列宽推导值，不允许出现"跨列空洞"
- [ ] 吸顶/吸底元素高度用 JS 实测同步为布局令牌（ResizeObserver，不用 resize 监听）
- [ ] 打印样式存在且隐藏装饰层

## 维度④ 功能完整性与交互正确性（jsdom 冒烟断言）
- [ ] 初始渲染数量断言（列表项数、分组数、总任务数）
- [ ] 今日/当前定位断言（含日期越界：早于起点、晚于终点的 clamp）
- [ ] 核心写操作 → 持久化 → 界面刷新链路（勾选、切换、清除、重置）
- [ ] 重渲染不重放入场动画（重刷产物无入场类）
- [ ] 焦点保持：写操作重建 DOM 后焦点回到原控件
- [ ] 危险操作有确认门槛（confirm 拦截）
- [ ] 主题切换：属性切换 + 持久化 + meta/浏览器色同步
- [ ] ARIA 语义：当前项 aria-current、控件 aria-label、装饰层 aria-hidden

## 维度⑤ 动效流畅度与性能
- [ ] `@keyframes` 逐个核对：只动 `transform/opacity`；box-shadow/filter 例外须元素数 ≤1 且注释说明
- [ ] 无常驻 `will-change`（固定动画自动提层，常驻反而挤占显存）
- [ ] 无 `transition:all`；入场 delay 用 CSS 变量承载，hover 时 `transition-delay:0` 覆盖
- [ ] scroll 监听 `{passive:true}` + rAF 节流，只写合成属性
- [ ] `prefers-reduced-motion`： blanket 规则须同时锁 `animation-duration` 与 `animation-iteration-count`（只锁 duration 会让 infinite 动画高频空转）
- [ ] `prefers-reduced-transparency`：backdrop-filter 全量退实底，限定元素集合与对应断点
- [ ] `prefers-contrast: more`：深浅两分支都有
- [ ] 移动端减层：超大背景层在小视口/低端场景有降级

## 回归纪律
- 每轮修复完成后，**重跑全部既有断言 + 截图**，通过才进入下一轮
- 修复后立即读回被编辑区段，防编辑工具吞行
- 回归发现问题：先回滚该修复，根因定位后再重做，不带病叠加
