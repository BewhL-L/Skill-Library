# 字体与渲染优化

## 浏览器字体渲染基础

网页文字是矢量渲染，不存在"8K 分辨率"概念。浏览器按屏幕物理像素（DPR 1x/2x/3x）绘制文字。用户觉得"糊"通常是：
1. 抗锯齿没开对
2. `backdrop-filter:blur()` 让叠在上面的文字被背景模糊带一点
3. Windows 缩放设为 125%（非整数倍最糊）

## 必加的 CSS

```css
body{
  -webkit-font-smoothing:antialiased;
  -moz-osx-font-smoothing:grayscale;
  text-rendering:optimizeLegibility;
  -webkit-text-size-adjust:100%;
  font-synthesis-weight:exact;
  font-feature-settings:"tnum" 1,"lnum" 1;  /* 表格数字对齐 */
}
```

## 参数说明

| 属性 | 作用 |
|------|------|
| `-webkit-font-smoothing:antialiased` | Chrome/Safari 抗锯齿（平滑） |
| `-moz-osx-font-smoothing:grayscale` | Firefox/macOS 灰度渲染 |
| `text-rendering:optimizeLegibility` | 浏览器自动优化字距连字 |
| `font-feature-settings:"tnum" 1` | 数字等宽，避免跳动 |
| `font-synthesis-weight:exact` | 合成字重时保持精确 |

## 不要做的事

- 不要给文字加 `filter:blur()` 或 `drop-shadow()`（会触发合成层导致模糊）
- 不要用 `opacity:0.99` 包裹文字（会强制创建合成层）
- 不要在 `backdrop-filter` 元素内再嵌套 `backdrop-filter`（层数过深性能差）
- 不要用极细字重（100/200），Windows 上会糊成一团，用 400/500/600/700

## Windows 高分屏建议

- 缩放设为 **100% 或 150%**（125% 最糊）
- Chrome `chrome://flags` 保持默认
- 如果用 Edge，开启"使用硬件加速"

## 字体选择

- 中文：系统默认 `system-ui, -apple-system, "Segoe UI", "Microsoft YaHei"`
- 英文/数字：同上，不要额外加载 web font（会慢）
- 等宽数字：`font-feature-settings:"tnum"` 自动开启

## 字号层级

- H1：28px / 700
- H2：18px / 600
- 正文：14px / 400 / line-height 1.65
- 辅助：12px / 400 / muted
- 数字标签：11px / 700 / tabular-nums
