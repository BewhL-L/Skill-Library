## v2.3.1 — 2026-11-04
### 新增
- `references/engineering-baseline.md` 3.5 新增「提交粒度」：一个模块一条提交，判断标准是"能不能单独 revert、单独讲清楚"。
### 背景

## v2.2.4 — 2026-11-02

### 新增
- `references/engineering-baseline.md` 3.8 节「装了却没通电：四类静默失败」——六件套装上之后的主要失效方式是"装了没生效"，四类各给症状 / 根因 / 验收命令：
  1. **配置旁路**：业务代码在模块顶层 `from … import vector_store`，绕过工厂对 `VECTOR_PROVIDER` 的分支判断，切 provider 后该模块静默返回空（接口 200、日志无错）。同一错误出现在多处，说明缺的是"唯一入口"约束而非某几行 import。
  2. **绝对阈值**：BM25 的 IDF 分数量级随语料规模变化（N=1~2 时上界 ≈0.29），写死 `score >= 0.5` 等于在小语料上关掉检索。给出 `floor = min(ABS_MIN, top × RATIO)` 的正确写法与可证不变量。
  3. **加了启动期校验却没改快速开始**：校验拒绝 `.env.example` 的占位值，而文档仍让人照抄 → CI 绿但新人第一步就崩。配套动作固定为"加校验 → 改 `.env.example` → 改快速开始"。
  4. **异常只 catch 一半**：`asyncio.CancelledError` 继承 `BaseException`，`except Exception` 抓不到，流式接口断连时库里留下半条记录。

### 变更
- 3.3 质量门补「结果以机器可读产物为准」：以 `--junitxml` 的 `tests/failures/errors` 为唯一判据。终端摘要行与退出码都可能被环境改写（实测过一次"118 条全绿、退出码 1"）。
- 4 反模式表 5 种 → 7 种，新增「配置旁路」「绝对阈值」两行，检查方法指向 3.8。
- 6 交付前 checklist 新增 5 项：统一入口、相对门槛且该用例能红、快速开始实跑、取消路径落库、junit 判据。
- 第六步第 12 维自检新增两条：「六件套确实通电」「测试结论取产物」。
- 第三步「工程底座六件套」约束补一句"装完还要验证通电"，指向 3.8 节。
- 3.8 ② 的量化结论**换成实测表**（K1=1.5、B=0.75，语料 1/2/3/5/10 个 chunk 对应 0.2877 / 0.1823 / 0.1335 / 0.0870 / 0.0465，全部低于 0.5 门槛）。同时修正两处不准确表述：原写"N=1~2 上界 ≈0.29"，实测 N=2 只有 0.1823；补上"分数随语料变大反而下降"这个反直觉事实（因为 n 跟着 N 一起涨）。
- 3.8 ① 的验收命令改为**能在 `app/` 上跑空**的那条（原写法 `import \(.*_store` 会把工厂 `get_vector_store` 一并命中，规则无法执行）；并补"遗留单例只允许测试引用"的处理方式。
- 3.8 ④ 的示例签名与真实实现对齐（`_persist_stream_failure(message_id, partial, sources_data)`）。
- 同步三处引用点：README 参考表补 3.8、第三步「禁止假完备」补配置旁路与绝对阈值、第 12 维「一键自检」补"脚本不覆盖新增两条"。
- 与 `project-processization/references/05-文档一致性与防漂移.md`「数字从哪来」建立**交叉引用**：CI 判据只在 3.3、文档数字来源只在 05，不两处各维护一份。
- CHANGELOG 自身清理：合并历史遗留的**重复 H1**（`# Changelog` 与 `# 更新日志` 并存，`validate_md.py` 报 `[high]`）；规范说明句上移到文件顶部，旧条目 `## [2.1.1]` 起内容不变。

## 版本说明

### 版本号规则

- **主版本号（MAJOR）**：不兼容的架构变更或核心流程重写
- **次版本号（MINOR）**：向下兼容的功能性新增（如新增自检维度、新增 references）
- **修订号（PATCH）**：向下兼容的问题修正（如 Bug 修复、文档修正）

- **PetShare 宠物社交平台**（v1.0→v2.0 全程验证）：FastAPI 后端 + 微信小程序前端，9模型/8路由/12页面/16测试全通过，经历 5 轮自检和 P0-P3 内容设计优化
