# Frontend Audit Loop — 网页改造多轮自检收敛

对已完成视觉/功能改造的网页成品，执行**固定五维轮次**的自检循环（设计一致性 → 视觉美学 → 排版响应式 → 功能交互 → 动效性能），每轮「检查 → 修复 → 回归」，直到出现零发现轮收敛，最终输出带依据的"无需进一步优化"结论。

## 核心特性

- **维度固定、轮次可追**：每轮产出「通过项 / 已修复项」两栏清单，收敛判定有据可查
- **探针化验证**：溢出探针、主题块令牌 diff、jsdom 冒烟——能断言的不靠截图
- **防回归纪律**：每轮修复后全量重跑断言，修复不引入新问题
- **团队可选**：大改动自动编排 视觉/体验/工程 三方协作 + 主控交叉验收
