# 使用案例

> 本文档收集 project-scaffolder 的真实使用场景，帮助你理解在什么情况下、如何使用本 Skill。

## 案例 1：求职项目 — 宠物社交平台（真实案例）

### 背景

用户为了找工作，需要一个完整的全栈项目作为简历亮点。用户描述："宠物爱好者注册账号，互相交流关注，发布宠物日常照片，最终做出小程序或可上线的 app。"

### 使用过程

1. **触发**：用户说"我想做一个宠物爱好者社交平台"
2. **第一步**：识别为"软件/技术 + 社交"混合型项目，成功标准为"可上线的小程序 + 完整后端"
3. **第二步**：规划 WBS + 功能完整性矩阵（对照社交类标配清单，自动包含收藏/搜索/通知/评论点赞等 P1 功能）
4. **第三步**：生成 FastAPI 后端（9模型/8路由）+ 微信小程序前端（12页面）
5. **第四步**：输出人机分工表（AI 完成全部代码，用户负责跑通/理解/部署）
6. **第五步**：生成《项目全景总结与行动指南》（三篇递进，16章，含附录 G v3.0 详解）
7. **第六步**：12 维度自检，修复 5 个跑不通 Bug + 多轮内容设计优化
8. **第七步**：Git 初始化，7 次提交

### 产出

- 后端：FastAPI + SQLAlchemy + JWT + WebSocket，16 测试全通过
- 前端：微信小程序 12 页面，含私信/推荐/收藏/搜索/通知
- 文档：2500+ 行指导文档，含 20 道面试题
- 简历亮点：全栈项目 + 实时通信 + 推荐算法 + 内容完整性

## 案例 2：学习项目 — 全栈工程师成长计划

### 背景

用户是初学者，想系统学习全栈开发，需要一个完整的学习路径和练习项目。

### 使用过程

1. **触发**：用户说"我想做一个全栈工程师学习计划，从零开始到能找工作"
2. **第一步**：识别为"学习/成长 + 软件/技术"混合型
3. **第二步**：对照学习类标配清单，规划知识点讲解、练习题、进度跟踪、复习计划、测评
4. **第三步**：生成学习路径（初期/中期/后期）、知识点讲解文档、练习题集、时间表、复习计划
5. **第四步**：分工（AI 生成学习材料，用户负责实际练习和项目实战）
6. **第五步**：生成《全栈工程师成长指南》（三篇递进，含梯度验证任务）

### 产出

- 学习路径：6 个月规划，每周目标
- 知识点：Java/Python/前端/AI 工程化四大板块
- 练习题：每章配套基础/进阶/实战三级任务
- 进度跟踪：可打印的学习记录表

## 案例 3：商业项目 — 电商小店创业计划

### 背景

用户想开一家线上宠物店，需要完整的商业计划和运营方案。

### 使用过程

1. **触发**：用户说"我想做一个宠物用品电商小店的创业计划"
2. **第一步**：识别为"商业/创业 + 软件/技术"混合型
3. **第二步**：对照商业类标配清单，规划市场分析、财务模型、营销方案、SOP、团队、风险
4. **第三步**：生成商业计划书、财务模型（收入预测/成本结构/盈亏平衡）、获客方案、运营 SOP、合同模板
5. **第四步**：分工（AI 生成方案和模板，用户负责实际注册/采购/销售）

### 产出

- 商业计划书：10 章完整方案
- 财务模型：Excel 可编辑模板
- 营销方案：获客渠道 + 推广计划 + 转化漏斗
- 运营 SOP：日常运营流程 + 关键指标 + 应急预案

## 案例 4：个人生活项目 — 日本旅行计划

### 背景

用户计划去日本旅行 7 天，需要完整的行程规划。

### 使用过程

1. **触发**：用户说"帮我做一个日本 7 天旅行计划，东京+京都+大阪"
2. **第一步**：识别为"个人/生活"型项目
3. **第二步**：对照个人生活类标配清单，规划预算、行程表、住宿、交通、景点、美食、打包清单
4. **第三步**：生成每日行程表、预算表、酒店推荐、交通方案、景点门票信息、打包清单
5. **第四步**：分工（AI 生成计划和清单，用户负责实际预订和出行）

### 产出

- 行程表：7 天每日时间线，含交通衔接
- 预算表：总预算 + 分类预算 + 实际花费记录
- 打包清单：分类物品清单，可直接打勾
- 应急方案：紧急联系 + 保险 + 备用方案

## 选择建议

| 你的需求 | 推荐项目类型 | 核心产出 |
|----------|------------|---------|
| 做一个 App/网站/系统 | 软件/技术 | 代码 + 部署方案 + 指导文档 |
| 学一门技能/考一个证 | 学习/成长 | 学习路径 + 练习题 + 时间表 |
| 做自媒体/写课程/拍视频 | 内容/创作 | 内容大纲 + 模板 + 发布计划 |
| 做生意/开公司/做产品 | 商业/创业 | 商业计划 + 财务模型 + SOP |
| 写论文/做行业分析 | 研究/调研 | 调研框架 + 资料清单 + 报告模板 |
| 办活动/建团队/优化流程 | 活动/组织 | 活动方案 + 分工表 + 流程 |
| 旅行/装修/健身/理财 | 个人/生活 | 计划 + 预算 + 清单 + 时间表 |

**大多数项目是混合型**，比如"做一个社交 App"既是软件/技术，也是社交内容；"开一个网店"既是商业/创业，也可能需要软件/技术。Skill 会自动识别混合类型并适配。
