# 源码阅读助手

> 源码阅读助手。为 Java/Spring、Vue3、Python/FastAPI/LangChain 三大技术栈生成系统化源码阅读方案，包含阅读路线、核心流程梳理、设计模式分析、关键数据结构、性能优化点、源码阅读笔记模板。当用户需要读源码、要求生成源码阅读路线、询问"XX框架源码怎么读"、需要理解底层原理、或要求生成源码阅读笔记时使用。支持 Spring Framework/MyBatis、Vue3 响应式/渲染/编译器、FastAPI/LangChain 等核心框架的源码阅读。生成的阅读笔记与 Obsidian 知识库笔记联动。

---

## 功能特性

### 核心原则

- **目标驱动**：先明确阅读目标（学习什么、解决什么问题），不盲目通读
- **宏观到微观**：先理解整体架构，再深入核心流程，最后看细节实现
- **运行验证**：搭建可运行环境，通过断点/日志验证理解，不只是静态阅读
- **设计优先**：关注设计模式、架构思想、关键决策，不纠结每一行代码
- **输出笔记**：每读完一个模块输出阅读笔记，整理架构图和时序图，形成知识积累
