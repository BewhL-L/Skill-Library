# 学习路径规划器

> 全栈+AI工程化领域的学习路径规划器。根据指定技术栈或学习目标，自动生成分阶段（初期→中期→后期→专家）的完整学习路线，包含学习周期、核心知识点清单、验收目标、项目练习建议、知识点优先级和学习技巧。当用户需要制定学习计划、规划技术栈学习路线、询问"XX应该怎么学"、需要分阶段学习指南、或要求生成可追踪的学习清单时使用。支持 Java全栈、Vue3+TypeScript、Python全栈、AI应用开发（AIGC/Agent/RAG/LLM服务）四大方向。

---

## 功能特性

### 核心原则

- **由浅入深**：严格按「初期→中期→后期→专家」四阶段递进，不跳级
- **可验收**：每阶段必须有明确的验收目标（能做什么、能答什么），不是模糊的"了解"
- **项目驱动**：每阶段至少配 1 个实战项目，项目覆盖该阶段核心知识点
- **优先级标注**：每个知识点标注 P0（必学）/ P1（重要）/ P2（选学）
- **周期量化**：每阶段给出建议学习周期（周），每周给出学习量
