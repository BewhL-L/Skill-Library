# 面试准备教练

> 面试准备教练。为全栈+AI工程化方向的技术面试生成系统化准备方案，包含面试题型答题框架、技术知识点梳理、项目经验提炼、模拟面试问答、简历优化建议。当用户准备面试、需要面试题、要求生成答题框架、需要项目经验梳理、询问"面试会问什么"、或需要模拟面试时使用。支持 Java后端、前端开发、Python/AI工程、全栈/系统设计四大方向。生成的内容与 Obsidian 知识库笔记联动，可直接用于复习。

---

## 功能特性

### 核心原则

- **结构化答题**：每种题型有固定的答题框架，避免想到哪说到哪
- **量化结果**：项目经验用数字说话（性能提升 X%、用户量 X、节省 X 成本）
- **深度优先**：核心知识点深入到原理层面，不是背面试题答案
- **模拟实战**：通过模拟问答检验准备效果，发现薄弱环节
- **知识联动**：面试准备与知识库笔记联动，复习时直接查阅深度笔记
