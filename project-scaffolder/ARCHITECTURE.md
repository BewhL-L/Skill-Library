# 架构文档

> **注意**：本 Skill 为**纯文档型 Skill**，无代码架构。本文档说明 Skill 的"知识架构"——即文档组织和流程架构。

---

## 整体架构

```
project-scaffolder/
│
├── SKILL.md（核心控制层）
│   ├── 核心理念
│   ├── 触发条件
│   ├── 七步工作流程（第一步~第七步）
│   ├── 执行阶段动态调整
│   ├── 非文件型产物管理
│   ├── 输出规范
│   └── References 导航
│
├── references/（知识层，按需加载）
│   ├── project-types.md        → 7 大项目类型知识库
│   ├── division-rules.md       → 人机分工规则库
│   ├── doc-template.md         → 指导文档模板库
│   ├── verification-patterns.md → 验证任务模式库
│   └── content-completeness.md → 功能完整性清单库
│
└── 文档层（辅助文档）
    ├── README.md               → 项目首页
    ├── QUICKSTART.md           → 快速上手
    ├── CHANGELOG.md            → 版本记录
    └── ...
```

## 渐进式加载架构

Skill 使用三级加载系统管理上下文：

1. **元数据（name + description）**：始终在上下文（~100 字）
2. **SKILL.md 主体**：触发时加载（~330 行）
3. **references/**：按需加载（5 个文件，仅在对应步骤读取）

这种设计确保：
- 不触发时几乎不占用上下文
- 触发时只加载核心流程
- 详细知识仅在需要时才加载
