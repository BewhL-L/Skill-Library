# examples

两个用途：让人知道"合格长什么样"，以及"不合格具体差在哪一段"。

| 文件 | 内容 |
|---|---|
| `plan-skeleton-rag.md` | 一份 RAG 问答项目的**方案骨架节选**（8 部分各取一段，展示颗粒度，不是完整方案） |
| `bad-vs-good.md` | 同一句话的"差/好"对照，覆盖验收、选型、扩展方向、阶段产物 |

## 使用方式

1. 生成方案后，先对照 `bad-vs-good.md` 自检措辞；
2. 再对照 `plan-skeleton-rag.md` 检查颗粒度（是否细到"能照着做"）；
3. 最后跑 `TESTING.md` 的五条抽查。

## 注意

骨架节选**不是模板**——模板在 `references/`。示例的作用是定颗粒度，照抄内容会得到一份"看起来很像但和你项目无关"的方案。
