# 速查表生成器

> Obsidian 知识库速查表生成器。从知识库中提取指定技术领域或主题的高频核心知识点，生成一页纸速查表（Cheat Sheet）或结构化复习卡片，用于快速查阅和考前复习。支持命令速查、API速查、概念对比、架构要点、面试高频题等类型。当用户需要速查表、要求整理核心知识点、需要复习卡片、询问"XX常用命令"、或准备面试需要高频考点时使用。生成的速查表兼容 Markdown 格式，可直接保存到知识库，支持打印为 PDF。

---

## 功能特性

### 核心原则

- **一页纸原则**：速查表控制在 1-2 页 A4 纸内，信息密度高但不拥挤
- **高频优先**：只收录最常用、最容易忘、面试最常考的知识点，不追求全面
- **结构化**：使用表格、列表、分栏等结构化方式，便于快速定位
- **可打印**：Markdown 格式，支持直接打印为 PDF，排版适合 A4 纸
- **知识联动**：每个知识点标注对应知识库笔记链接，需要深入时可跳转
