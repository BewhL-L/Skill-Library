## 🎁 如何成为贡献者

### 1. 代码贡献

1. Fork 项目
2. 创建功能分支：`git checkout -b feature/amazing-feature`
3. 提交更改：`git commit -m 'feat: add amazing feature'`
4. 推送分支：`git push origin feature/amazing-feature`
5. 提交 Pull Request

详细指南请查看 [CONTRIBUTING.md](CONTRIBUTING.md)。

### 2. 文档贡献

- 修复错别字和语法错误
- 改进文档清晰度
- 添加使用示例
- 翻译文档到其他语言
- 更新过时的文档

### 3. Bug 报告

在 [GitHub Issues](https://github.com/your-username/obsidian-knowledge-base-creator/issues) 中报告 Bug，请使用 Bug 报告模板，包含：
- 清晰的 Bug 描述
- 详细的复现步骤
- 环境信息
- 错误日志和截图

### 4. 功能建议

在 [GitHub Issues](https://github.com/your-username/obsidian-knowledge-base-creator/issues) 中提交功能请求，请使用功能请求模板，包含：
- 功能描述
- 解决的问题
- 提议的解决方案
- 预期效果

### 5. 其他贡献方式

- ⭐ 给项目点 Star
- 📢 分享给更多人
- 💬 在社区回答问题
- 🎨 设计 Logo、图标、宣传图
- 💰 赞助项目（参考 [.github/FUNDING.yml](.github/FUNDING.yml)）
