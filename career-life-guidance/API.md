# API 参考

> 本文档描述 career-life-guidance Skill 的接口规范。由于本Skill为纯文档型（doc-only），不包含可执行代码，本文档描述的是Skill的概念性接口和资源引用方式。

## 概述

career-life-guidance 是一个纯文档型 Skill，通过提供标准化的文档模板、参考文档和工作流程，帮助 AI Agent 为普通背景个体生成"从决策到站稳脚跟"的全周期人生与职业指导手册。

## 输入接口

### 用户身份字段（8个必填）

生成手册前必须锁定以下8个身份字段：

| 字段 | 说明 | 示例 |
|------|------|------|
| 学历背景 | 学校层次、专业 | 普通一本/计算机科学 |
| 当前阶段 | 在校/工作/待业/转行 | 大三在读 |
| 工作经验 | 年限、行业、职位 | 2年/机械/工程师 |
| 年龄 | 实际年龄 | 24岁 |
| 所在城市 | 城市层级、生活成本 | 新一线城市 |
| 目标设定 | 薪资、职位、时间 | 月薪15k/1年内入职 |
| 约束条件 | 经济、时间、家庭 | 可支撑6个月全职学习 |
| 偏好倾向 | 兴趣、性格、风险承受 | 喜欢前端、风险中等 |

### 触发场景

本Skill在以下场景触发：
- 用户询问职业方向选择（"A还是B"）
- 用户要求转行/学习路线规划
- 用户需要项目实战指导
- 用户需要求职/简历/面试帮助
- 用户询问中长期职业发展/35岁危机
- 用户要求整合一份完整的人生指导文档

## 输出接口

### 交付格式

- **文件类型**：Markdown文档（.md），支持Obsidian双链格式
- **结构**：六篇人生时间线 + 固定套件
- **量级**：简版2-5万字 / 标准版5-10万字 / 完整版10-20万字
- **交付方式**：通过文件输出，可直接导入Obsidian等知识库

### 成品固定套件（缺一件都不算完整手册）

1. **写在前面** - 致读者的信 + 使用指南
2. **能力总览** - 全书能力地图 + 优先级矩阵
3. **六篇正文** - 决策/学习/项目/求职/发展/支撑
4. **篇小结** - 每篇结束后的行动清单 + 检查点
5. **收尾套件** - 资源清单、工具推荐、书单、模板、FAQ
6. **文档信息** - 版本、更新日志、使用说明、免责声明

### 质量标准

交付前必须通过校验清单（详见SKILL.md"交付前校验清单"章节）：
- 8个身份字段已锁定
- 六篇结构完整
- 项目篇占25%-35%篇幅
- 每个建议包含"为什么+怎么做+不做后果"
- 至少3个从易到难的完整项目
- 写作风格符合"前辈语气"配方
- 密度指标达标（每1000字至少1个可执行动作）

## 工作流接口

### 8步标准工作流程

```
1. 身份校准 → 锁定8个身份字段
2. 赛道选择与取证 → 多方向对比、行业取证、三情景推演
3. 搭建全书骨架 → 六篇结构、固定套件、章节规划
4. 填充学习路线 → 时间线、资源、方法、心态
5. 填充项目实战 → 3-5个项目，完整实现指南（重中之重）
6. 填充求职与长期发展 → 简历、面试、晋升、跳槽、35岁
7. 补齐支撑维度与风险预案 → 身体/心理/理财/社保/品牌/人脉/英语
8. 标准化输出与校验 → Obsidian格式、流程图、校验清单
```

### 多轮迭代接口

手册通常需要迭代3-5版，每轮有明确的深化方向：
- 第1版：骨架完整 + 核心内容
- 第2版：项目实战深化 + 表格流程图补充
- 第3版：求职细节 + 支撑维度补齐
- 第4版：长期发展 + 风险预案
- 第5版：整体润色 + 密度提升 + 格式标准化

详见 `references/11-iteration-protocol.md`
