# FAQ

## Q1: 为什么我打开页面是空白？
A: 检查 `{{STAGES_JSON}}` 是否被替换成了合法的 JS 数组。模板里如果还留着 `{{...}}`，JS 会语法错误。

## Q2: 勾选进度刷新后丢了？
A: 检查两个项目的 `STORAGE_KEY` 是否相同。不同项目必须用不同 key，否则会互相覆盖。

## Q3: 周导航不显示？
A: 右侧导航只在屏幕宽度 >1100px 时显示，窄屏自动隐藏，这是设计如此。

## Q4: 怎么改主题色？
A: 不要改组件里的颜色，改 `:root` 里的 `--accent` / `--accent-2` / `--accent-3` / `--accent-4` 四个变量。

## Q5: 想加新的模块（图表/日历）？
A: 这个 skill 是排期表专用，不要往里加图表。如果需要图表，用 `Process-oriented-Web-Design` skill（紫色玻璃风看板）。

## Q6: 任务条数超过 14 条，为什么后面的没有错峰动画？
A: 模板只写了 14 档 `transition-delay`。超过 14 条的任务会统一在 0.52s 出现，视觉上仍然整齐，不影响功能。

## Q7: 怎么改开始日期？
A: 改 `const START = new Date(2026,9,16);`。注意月份从 0 开始：10 月 = 9。

## Q8: 支持多语言吗？
A: 模板默认中文，把 `:root` 外的文案替换即可，不需要改 CSS。
