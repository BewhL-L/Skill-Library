# 数据层生成规范

## CFG 对象结构

```js
const CFG = {
  title: "RAG+Agent 学习",
  start: new Date(2026, 9, 12),   // 月从 0 开始，10 月 = 9
  end:   new Date(2027, 3, 30),   // 4 月 = 3
  dailyH: 8,
  storageKey: "ragstudy-v1",
  phases: {1:"阶段0·环境",2:"阶段1·基础",3:"阶段2·RAG",4:"阶段3·Agent",5:"阶段4·LangGraph",6:"阶段5·项目",7:"缓冲"},
  basePlan: [...]
};
```

## BASE_PLAN JSON 结构

每周一个对象：

```js
[
  {
    "w": 1,           // 周号（1 开始）
    "ph": 1,          // 阶段（对应 CFG.phases 的 key）
    "t": "环境就绪",  // 周标题
    "days": [
      [["装 WSL2",2],["装 Docker",3],["读 README",3]],   // 周一 8h
      [["学 FastAPI",4],["写 hello world",4]],            // 周二
      [["任务",学时],...],                                  // 周三
      [["任务",学时],...],                                  // 周四
      [["任务",学时],...],                                  // 周五
      [["任务",学时],...],                                  // 周六
      [["复习卡片",0.3],["周复盘",1.5],["缓冲",2.2]]        // 周日 4h
    ]
  },
  // ... 更多周
]
```

## 自动排周算法

如果用户只给了阶段名和周数，没给具体任务：

1. 计算总周数 `weeks = floor((end-start)/7)`
2. 把周数按阶段数平均分配（最后一周给缓冲）
3. 工作日每天 8h，拆成 2-3 个任务
4. 周日 4h（卡片 0.3 + 复盘 1.5 + 缓冲 2.2）
5. 任务标题用阶段名 + "第 N 周：知识点"

## 周数计算

```python
from datetime import date
start = date(2026,10,12)
end = date(2027,4,30)
weeks = (end-start).days // 7
# 29 周
```

## storageKey 命名

格式：`<项目缩写>-v<版本>`
- RAG+Agent → `ragstudy-v1`
- 求职冲刺 → `jobhunt-v1`
- 全栈项目 → `fullstack-v1`

不要复用旧 key，否则用户上次的打卡数据会残留。
