## 色彩系统

## 玻璃拟态（Glassmorphism）

### 核心参数
```css
background: var(--bg-glass);
backdrop-filter: blur(24px) saturate(160%);
border: 1px solid var(--line);
box-shadow: var(--shadow-md), var(--shadow-inset);
```

### 使用场景
- 导航栏背景
- 卡片容器
- 统计数据卡片
- 弹窗/模态框
- 悬浮工具栏

### 注意事项
1. `backdrop-filter` 性能消耗较大，大量使用时考虑降低到 `blur(16px)`
2. 必须配合半透明背景色才能看到效果
3. 内阴影 `--shadow-inset` 营造顶部高光，增强玻璃质感
4. 浅色主题下背景透明度应更高（`.7`），深色主题可稍低（`.62`）

## 排版系统

### 字体栈
```css
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif;
```

### 字号层级
| 层级 | 字号 | 字重 | 用途 |
|------|------|------|------|
| Hero标题 | `clamp(32px, 5vw, 56px)` | 800 | 页面主标题 |
| 章节标题 | `clamp(24px, 3vw, 36px)` | 700 | 各章节大标题 |
| 卡片标题 | `18px` | 600 | 卡片内标题 |
| 正文 | `16px` | 400 | 段落正文 |
| 辅助文字 | `14px` | 400 | 卡片描述、说明 |
| 标签文字 | `13px` | 400 | 统计卡片标签 |
| 大数字 | `32px` | 700 | 统计数字 |

### 行高
- 标题：`1.2`
- 正文：`1.6`
- 卡片描述：`1.6`

### 字间距
- 大标题：`-0.02em`
- 章节标题：`-0.01em`
- 正文：`normal`

- 最大内容宽度：`1400px`
- 页面左右内边距：`32px`（桌面）/ `16px`（移动端）
- 章节上下内边距：`80px`（桌面）/ `60px`（移动端）

## 动效系统

### 缓动函数
```css
--ease: cubic-bezier(.16, 1, .3, 1);
```

### 常用时长
- 悬停过渡：`0.3s`
- 入场动画：`0.7s`
- 主题切换：`0.4s`
- 导航栏变化：`0.3s`

### 入场动画
```css
.reveal {
  opacity: 0;
  transform: translateY(30px);
  transition: opacity .7s var(--ease), transform .7s var(--ease);
}
.reveal.visible {
  opacity: 1;
  transform: translateY(0);
}
```

### 悬停效果
```css
.card:hover {
  transform: translateY(-4px);
  box-shadow: var(--shadow-lg), var(--shadow-inset);
}
```

### 减少动画偏好
必须支持 `prefers-reduced-motion: reduce`，禁用所有动画和过渡。

## 响应式断点

| 断点 | 宽度 | 布局变化 |
|------|------|----------|
| 桌面 | `> 1024px` | 多列网格、完整导航 |
| 平板 | `768px - 1024px` | 减少列数、简化导航 |
| 手机 | `< 768px` | 单列布局、隐藏导航链接、缩小间距 |

### 移动端适配要点
1. 导航栏隐藏链接，保留Logo和主题切换
2. 卡片网格改为单列
3. 缩小Hero区域内边距
4. 统计卡片缩小尺寸
5. 字号适当减小

## 组件设计原则

### 卡片设计
- 统一使用玻璃拟态样式
- 图标区域：48x48px，圆角12px，渐变背景
- 标题与描述层级分明
- hover时上浮4px + 阴影加深

### 统计卡片
- 数字使用强调色（4种颜色循环）
- 数字字号32px，标签13px
- 最小宽度140px
- 水平排列，自动换行

### 导航栏
- 固定顶部，高度64px
- 玻璃拟态背景
- 滚动时添加阴影
- 主题切换按钮：胶囊形开关

## 可访问性

1. **对比度**：文字与背景对比度至少 4.5:1
2. **焦点状态**：所有可交互元素有明显的焦点样式
3. **语义化HTML**：使用正确的标签（nav, section, footer等）
4. **ARIA标签**：图标按钮添加 `aria-label`
5. **键盘导航**：所有功能可通过键盘操作
6. **减少动画**：尊重 `prefers-reduced-motion` 设置
