# 支持

## 排查顺序（大多数问题在这三步解决）

1. **跑自测**：`python tests/test_gate.py`。红了说明环境或规则坏了，看失败用例的名字。
2. **直接跑闸门**：`python scripts/gate.py <仓库> --staged`（或 `--all`），把完整输出贴出来——`文件:行 [规则]` 三段定位到具体规则 id。
3. **看钩子**：`bash .git/hooks/pre-commit` 单独执行。它报错就与 git 无关，是路径或 Python 解释器的问题。

## 常见问题

见 [FAQ.md](FAQ.md)——误报怎么加白名单、钩子为什么不生效、为什么不扫历史。

## 提 Issue 时请带

- 命令与完整输出（含退出码：`echo $?`）
- OS 与 Python 版本（`python -V`）
- 用**假数据**构造的最小复现文件（运行时拼接，不要贴真实密钥）

## 仍解决不了

联系维护者，或查看 [SECURITY.md](SECURITY.md) 的能力边界——有些"漏报"属于设计范围（熵检测、历史扫描不在本技能内）。
