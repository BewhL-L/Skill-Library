# 练习题设计模式与题库参考

> 供 code-practice-generator 设计练习题时参考，确保题目有梯度、有解析、有实战价值。

## 一、练习题设计原则

### 基础题（3道）
- **目标**：验证基本概念理解，能照着示例写出来
- **难度**：⭐⭐
- **形式**：填空、修改现有代码、实现简单功能
- **时间**：每道 10-15 分钟
- **解析要求**：逐行解释，说明每个参数的作用，指出常见错误

### 进阶题（2道）
- **目标**：理解底层机制，能灵活运用解决实际问题
- **难度**：⭐⭐⭐
- **形式**：实现完整功能、排查 Bug、性能优化
- **时间**：每道 30-45 分钟
- **解析要求**：说明设计思路、对比不同方案、指出常见坑

### 挑战题（1道）
- **目标**：综合运用多个知识点，达到生产环境水平
- **难度**：⭐⭐⭐⭐
- **形式**：设计完整方案、实现复杂功能、源码级扩展
- **时间**：60-90 分钟
- **解析要求**：架构设计思路、trade-off 分析、扩展方向、多种方案对比

## 二、各技术栈练习题示例

### Java / Spring Boot

#### 基础题
1. **实现一个简单的 RESTful API**：创建一个 UserController，提供 GET /users 和 POST /users 接口，返回固定数据
2. **使用 MyBatis 实现单表 CRUD**：基于 user 表，实现增删改查，使用 XML 映射文件
3. **配置 Redis 缓存**：为一个查询方法添加 @Cacheable 注解，验证缓存生效

#### 进阶题
1. **实现统一异常处理**：使用 @ControllerAdvice + @ExceptionHandler，统一处理业务异常和参数校验异常，返回统一格式的错误响应
2. **排查循环依赖问题**：给定一个存在构造器循环依赖的 Spring Boot 项目，分析报错原因并提供 3 种解决方案

#### 挑战题
1. **实现一个分布式限流注解**：自定义 @RateLimit 注解，基于 Redis + Lua 脚本实现分布式限流，支持配置 QPS、限流 key（用户/IP/接口），并在限流时返回自定义错误信息

---

### Vue3 + TypeScript

#### 基础题
1. **实现一个计数器组件**：使用 ref 实现计数，包含增加、减少、重置按钮，显示当前值
2. **使用 computed 计算属性**：实现一个全名显示组件，输入姓和名，自动计算全名（中文姓在前，英文名在前）
3. **实现父子组件通信**：父组件传递列表数据给子组件，子组件点击删除时通知父组件更新

#### 进阶题
1. **实现一个自定义 useDebounce Hook**：封装一个防抖函数，支持传入回调函数和延迟时间，返回防抖后的函数和取消方法，使用 TypeScript 泛型
2. **排查响应式丢失问题**：给定一个使用 reactive 对象解构后失去响应式的组件，分析原因并提供 3 种修复方案（toRefs/toRef/storeToRefs）

#### 挑战题
1. **实现一个虚拟列表组件**：支持 10000 条数据的流畅滚动，动态计算可视区域、渲染可见项、使用 IntersectionObserver 或滚动事件，支持动态高度和固定高度两种模式

---

### Python / FastAPI

#### 基础题
1. **实现一个 Hello World API**：使用 FastAPI 创建 GET /hello 接口，支持 name 查询参数，返回 {"message": "Hello, {name}"}
2. **使用 Pydantic 定义请求体**：创建一个用户注册接口，定义 UserCreate 模型（用户名/邮箱/密码），添加字段校验（邮箱格式、密码长度）
3. **实现依赖注入**：创建一个 get_db 依赖，在多个路由中复用数据库连接

#### 进阶题
1. **实现 JWT 认证**：使用 python-jose 实现 JWT 令牌生成和验证，创建登录接口返回 token，创建受保护接口验证 token，使用 FastAPI 的 Depends 注入当前用户
2. **排查异步阻塞问题**：给定一个在 async 路由中调用同步阻塞函数（如 time.sleep）导致并发下降的代码，分析原因并提供 3 种解决方案（run_in_threadpool/改异步/使用队列）

#### 挑战题
1. **实现一个文件上传与处理管道**：支持大文件分片上传、断点续传、上传后异步处理（使用 Celery）、处理进度查询、结果下载，包含错误处理和超时机制

---

### AI 应用 / LangChain

#### 基础题
1. **实现一个简单的 LLM 调用**：使用 LangChain 的 ChatOpenAI，调用大模型生成一首五言绝句，支持流式输出
2. **实现一个 Prompt Template**：创建一个翻译模板，支持输入源语言、目标语言、文本，输出翻译结果，使用 OutputParser 解析为 JSON
3. **实现一个简单的 RAG**：加载一个文本文件，切分后存入 Chroma，实现检索 + 生成的问答流程

#### 进阶题
1. **实现一个带工具调用的 Agent**：使用 LangChain 的 Agent，集成 3 个工具（计算器/天气查询/知识库检索），实现 ReAct 推理过程，处理工具调用失败的情况
2. **优化 RAG 检索质量**：给定一个检索效果差的 RAG 系统（答案不相关/遗漏信息），分析原因并提供 5 种优化方案（切分策略/Embedding 模型/重排序/查询改写/多路召回）

#### 挑战题
1. **实现一个多 Agent 协作系统**：设计一个包含 3 个 Agent（研究员/写作员/审核员）的协作系统，研究员负责检索资料，写作员负责生成文章，审核员负责检查质量并反馈修改，使用 LangGraph 实现状态管理和循环流程

## 四、练习题质量检查清单

- [ ] 题目描述清晰，需求明确，无歧义
- [ ] 基础题 3 道、进阶题 2 道、挑战题 1 道，数量完整
- [ ] 难度梯度合理，基础题不涉及进阶知识点
- [ ] 每道题有明确的验收标准（怎么算做对了）
- [ ] 答案代码完整可运行（包含导入、配置、使用示例）
- [ ] 解析详细，基础题逐行解释，进阶题有思路分析
- [ ] 挑战题有架构设计和多种方案对比
- [ ] 题目与对应技术概念强相关，不偏题
- [ ] 代码注释中标注了关键概念的知识库链接
