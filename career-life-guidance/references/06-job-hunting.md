## 1. 求职渠道优先级

按"学历筛选弱、能直接触达决策者"排序：

1. **直聊型招聘平台**（可直接和业务/技术负责人聊，学历筛选最弱）——首选
2. 社区内推（技术社区、脉脉、V2EX、学长/学习伙伴内推）——内推比海投效率高数倍
3. 垂直招聘平台
4. 猎头（适合有经验后）
5. 公司官网投递（HR 学历筛选最严，转行初期不作为主渠道）

原则：多渠道并行，把主要精力放在直聊和内推上。

## 2. 对普通背景最友好的公司类型与路径

按友好度排序（结合方向调整）：
- 新兴方向创业公司（人才稀缺、只看能力、成长快）★★★★★
- 中小公司相关岗位（能独当一面、项目经验快速积累）
- 传统企业数字化/信息化团队（稳定、竞争小）
- 外包相关项目组（兜底先入行，不宜久留）
- 远程工作（能力导向、弱化背景）

**分阶段路径**：第一份去能快速积累完整项目经验的中厂/成长期公司 → 2-3 年用项目经验对冲学历、跳更好平台镀金并涨薪 → 之后在专家/管理/独立开发间选路。

## 3. 作品集与 GitHub

- GitHub 是"第二简历"：头像简介完整、置顶优质仓库、保持提交活跃、给开源提 PR
- 每个项目仓库：高质量 README、在线 Demo、清晰 commit 历史、规范目录
- 作品集必须覆盖三类：一个完整全栈应用、一个目标方向核心项目、一个有真实用户的产品
- 每个项目都要有**可在线点击的演示链接**（部署方法见项目篇第 7 步）

## 4. 简历写法（一页纸，STAR-R）

结构顺序（学历放最底部，弱化背景）：
个人信息 → 个人优势（3 行）→ **个人项目（占 40%-50% 篇幅，核心）** → 工作/实习经历 → 技能栏 → 教育背景

- 项目用 **STAR-R**：情境 Situation → 任务 Task → 行动 Action → 结果 Result（量化）→ 反思 Reflection
- 每条至少 2 个量化数字（性能提升、用户数、耗时下降、覆盖率等）
- 技能栏只写能被项目和面试支撑的，不堆砌名词
- 不写"精通"，用"熟悉/了解"分级，避免被深挖打脸

## 5. 投递节奏与漏斗管理

- 先用 10-20 家练手（不最想去的），暴露问题、迭代话术
- 之后每天稳定投一定数量，累计数百家是常态；用表格跟踪公司/岗位/进度/反馈
- 边面边补：面试暴露的薄弱点当晚补，不要"全部准备好再投"
- 记录每次面试被问倒的问题，形成个人题库

## 6. 面试结构与项目讲法

面试权重（应用工程岗典型）：项目讲解 ~40% > 方向专业基础 ~25% > 工程/语言基础 ~20% > 算法 ~10% > 行为面 ~5%（按目标岗位 JD 校准）。

项目讲法准备两版：
- **3 分钟电梯版**：是什么 + 技术栈 + 你做了什么 + 最亮的成果
- **10 分钟详细版**：背景 → 架构（边画图边讲）→ 技术选型权衡 → 最大难点与解法 → 成果数据 → 如果重做会怎么改进

高频追问预演：为什么选这个技术？最大难点？怎么解决？系统能扛多少量？瓶颈在哪？怎么扩展？（完整题库方法见项目篇）

## 7. 薪资预期与谈判

- 给该方向、该城市、初/中级的现实薪资区间，明确"不接受低于 X"的底线，避免被压价
- 拿到 offer 前不先报价；被问期望给区间（下限=可接受值）
- 用多个 offer 互相抬价，通常有一定议价空间；谈总包（base+绩效+期权/股票+补贴）而非只看 base
- 稀缺方向议价权更高，但不要虚报被背调戳穿

---

## 8. offer 评估与签约注意

六维评估：薪资总包、技术成长、业务前景、直属领导/团队、工作强度、公司稳定性（权重见长期发展篇跳槽章节）。

合同/社保必看：
- 试用期时长与工资（不超法定上限、不低于法定比例）
- 竞业限制（须有补偿金才有效，看范围和期限）
- 工资构成、加班费、五险一金缴纳基数
- 保留 offer、合同、考勤、工资条等证据；公司违法时劳动仲裁免费且对劳动者相对友好，不要怕维权

## 9. gap 与转行原因标准话术

- gap 期主动表述为"全职系统学习 X 个月并完成 N 个可上线项目"，不是"待业"
- 转行原因模板（理性、自驱、有准备）：
  > 我用 X 个月全职系统学习了……完成了……具备独立交付……的能力。这是我深入了解和持续实践后的理性选择，不是一时冲动。
- **绝不说**：老东家坏话、"就是工资高"、"在家待了很久不知道干嘛"
- 把转行叙事转成优势：自驱、学习能力、为目标做了充分准备

## 10. 地区差异（简版）

技术栈与机会有明显城市聚集（如某些城市某语言/某行业生态更强）。求职前按目标城市的岗位 JD 反推主推技术栈；城市深度对比、定居与落户见 `07-longterm-development.md`。
