# 技术概念三位一体深度拆解器

> 技术概念三位一体深度拆解器。对全栈+AI工程化的核心技术概念进行深度拆解，必须同时涵盖三个维度：作用（解决什么问题）、底层原理（核心逻辑/架构/工作流程/源码）、用法要点（实操示例/最佳实践/常见坑/性能优化）。当用户需要深入理解某个技术概念、要求讲解底层原理、询问"XX技术怎么用"、需要生成深度技术笔记、或学习笔记内容太浅需要深化时使用。支持 Java/JVM/Spring、Vue3/TypeScript、Python/FastAPI、AI/LLM/RAG/Agent、数据库/缓存、分布式系统等方向的核心概念拆解。生成的拆解笔记与 Obsidian 知识库联动。

---

## 功能特性

### 核心原则

- **三位一体强制**：每个概念必须同时涵盖作用、底层原理、用法要点三个维度，缺一不可
- **原理到源码**：高级及以上难度的概念必须深入到源码层面，提供核心代码片段和注释
- **问题导向**：从"解决什么问题"出发，而不是从"是什么"出发，理解技术的价值
- **实践落地**：用法要点必须有可运行的代码示例、最佳实践、常见坑，不是空泛的"注意性能"
- **批判思维**：包含 trade-off 分析，说明技术的优势和劣势，不盲目吹捧
