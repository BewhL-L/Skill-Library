# 论文精读助手

> 对 AI 方向论文进行**系统化精读**，生成核心方法、实验结果、关键贡献、局限性、实践启发的精读笔记，解决"论文读不懂、读完就忘、不知道怎么用"的问题。

---

## 核心原则

1. **先判断价值**：通过标题、摘要、引用量判断论文是否值得精读，不盲目精读
2. **八步精读法**：按固定流程精读，确保不遗漏关键信息
3. **批判思维**：不只接受论文结论，要思考局限性、实验是否充分、结论是否可靠
4. **关联知识库**：论文中的核心概念与已有笔记关联，形成知识网络
5. **实践导向**：提炼可以应用到项目/学习中的点，不只是理论理解

---

## 论文精读八步法

| 步骤 | 内容 | 时间 | 产出 |
|------|------|------|------|
| 1. 标题与摘要 | 判断论文价值、核心问题、方法、结果 | 5分钟 | 是否精读的判断 |
| 2. 引言与相关工作 | 研究背景、现有方法局限、本文创新点 | 10分钟 | 研究动机和定位 |
| 3. 方法概述 | 整体架构、核心模块、关键公式、训练目标 | 15分钟 | 架构图和核心方法理解 |
| 4. 实验设计 | 数据集、评估指标、基线方法、消融实验 | 10分钟 | 实验设置理解 |
| 5. 结果分析 | 主要结果、对比、消融、案例分析 | 15分钟 | 核心结论和数据 |
| 6. 局限性与讨论 | 作者承认的局限、你的疑问、改进方向 | 10分钟 | 批判思考 |
| 7. 与知识库关联 | 核心概念整理、方法对比、实践启发 | 10分钟 | 知识关联 |
| 8. 总结与输出 | 一句话总结、3个takeaway、精读笔记 | 10分钟 | 精读笔记 |

> 八步法的详细执行要点和论文笔记模板详见 [references/paper-reference.md](references/paper-reference.md)

## AI 方向论文分类与精读重点概览

> 五大方向（LLM、RAG、Agent、多模态、高效训练/推理优化）的代表论文、精读重点、关键问题详见 [references/paper-reference.md](references/paper-reference.md)，精读论文时按对应方向的重点执行。

| 方向 | 代表论文 | 精读重点 |
|------|---------|---------|
| 大语言模型 LLM | Transformer、GPT系列、LLaMA、PaLM | 架构改进、训练策略、对齐方法、涌现能力、效率优化 |
| RAG 检索增强 | RAG、REALM、RETRO、Atlas、Self-RAG | 检索器、生成器融合、切分策略、重排序、评估方法 |
| Agent 智能体 | ReAct、Toolformer、Reflexion、Generative Agents | 规划、记忆、工具使用、推理、多Agent协作 |
| 多模态 | CLIP、BLIP-2、GPT-4V、LLaVA、Flamingo | 视觉编码器、对齐方式、指令微调、能力评估 |
| 高效训练/推理 | LoRA、QLoRA、FlashAttention、Speculative Decoding、PagedAttention | 参数高效微调、量化、注意力优化、推理加速、显存优化 |

## 使用示例

**输入**："帮我精读这篇《Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks》论文，生成精读笔记存入知识库"

**输出**：
- 论文基本信息（标题、作者、机构、发表时间、arXiv 链接、代码链接）
- 八步法精读笔记：
  - 研究背景和动机（现有生成模型的知识缺失问题）
  - 核心方法（RAG 架构：检索器 + 生成器，参数化记忆 + 非参数化记忆）
  - 架构图（文档索引→查询检索→上下文拼接→生成）
  - 实验设计（数据集：Natural Questions、WebQuestions、TriviaQA；评估指标）
  - 主要结果（RAG 比参数化模型在开放域问答上提升显著）
  - 消融实验（检索器质量、检索数量、融合方式的影响）
  - 局限性（检索延迟、错误传播、长上下文限制）
  - 与知识库关联（[[RAG]] [[向量检索]] [[Embedding]] 等双链）
- 关键 Takeaway（3 个核心要点）
- 实践启发（可以应用到项目中的点）
- 存入知识库对应分类（AI论文精读）
- 与 `[[论文精读方法]]` `[[RAG检索增强]]` 等知识库笔记双向链接

## 工作流程

### 场景一：完整论文精读

1. **论文信息收集**：
   - 论文标题、作者、机构、发表时间
   - arXiv 链接、代码链接
   - 引用量、社区评价

2. **快速判断**（八步法前两步）：
   - 读标题和摘要，判断核心贡献
   - 读引言，理解研究动机
   - 判断是否值得精读（与学习方向相关度、创新性、影响力）

3. **深度精读**（八步法第三至第六步）：
   - 方法概述：画出架构图，理解核心模块
   - 实验设计：理解数据集、指标、基线
   - 结果分析：提取核心数据和结论
   - 局限性：批判思考，提出疑问

4. **知识关联**（八步法第七步）：
   - 论文中的核心概念与知识库笔记关联（添加 `[[]]` 双链）
   - 与类似方法/论文对比（生成对比表）
   - 提炼实践启发（可以应用到项目中的点）

5. **输出精读笔记**（八步法第八步）：
   - 按论文笔记模板生成完整精读笔记
   - 存入知识库对应分类
   - 标注难度和阅读日期

### 场景二：论文快速解读

1. 用户提供论文标题或链接
2. 快速阅读标题、摘要、引言、结论
3. 生成快速解读：
   - 一句话总结
   - 核心问题
   - 核心方法（3句话）
   - 主要结果
   - 关键贡献
   - 局限性
   - 是否值得精读的建议

### 场景三：论文对比分析

1. 确认要对比的论文（2-3篇）
2. 分别精读每篇论文的核心方法
3. 生成对比分析：
   - 研究问题对比
   - 方法对比（架构、关键技术、创新点）
   - 实验结果对比
   - 优势和劣势对比
   - 适用场景对比
   - 演进关系（谁基于谁、谁改进了谁）
4. 生成对比表格和总结

### 场景四：AI 前沿跟踪

1. 确认关注方向（如"最近 RAG 有什么新论文"）
2. 搜索该方向最新论文（近 3-6 个月）
3. 筛选高价值论文（引用量、机构、社区热度）
4. 为每篇论文生成快速解读（一句话总结 + 核心贡献）
5. 生成前沿趋势总结：
   - 该方向的研究热点
   - 关键技术演进
   - 值得深入阅读的论文
   - 对实践的指导意义

## 输出规范

1. 精读笔记必须包含八步法的所有产出，不遗漏
2. 核心方法必须有架构图描述（文字或 Mermaid），不能只有文字
3. 实验结果必须有具体数据（表格或数字），不是"效果很好"
4. 局限性必须包含作者承认的和你自己发现的
5. 关键 Takeaway 必须具体可执行，不是"这篇论文很重要"
6. 所有核心概念添加 `[[]]` 双链，与知识库关联
7. 论文笔记必须包含论文链接和代码链接
8. 快速解读必须在 500 字以内，抓住核心

## 与其他 Skill 的协作

- **与 `tech-concept-deep-dive` 协作**：论文中的核心技术概念用深度拆解器生成详细笔记，论文精读引用这些笔记
- **与 `project-based-learning` 协作**：论文中的方法可以转化为项目实践，用项目驱动学习生成器生成项目方案
- **与 `code-practice-generator` 协作**：论文中的核心算法用代码实践生成器生成可运行的实现
- **与 `knowledge-review-spaced` 协作**：论文精读笔记纳入复习计划，间隔重复巩固
- **与 `learning-path-planner` 协作**：AI 方向的论文阅读纳入学习路线的专家阶段
- **与 `cheatsheet-generator` 协作**：论文核心方法、关键公式整理成速查表
- **与 `english-for-developers` 协作**：技术英语打牢长难句与学术词汇基础，本 skill 在此之上做论文级精读与方法复现
