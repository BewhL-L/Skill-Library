# HTML Page Creator

专业网页创建与设计Skill，基于成熟的玻璃拟态设计系统，快速生成高质量单页HTML网站。

## 核心能力

1. **从零创建网页** - 基于内置模板，快速生成结构完整、设计精美的HTML页面
2. **内容定制** - 根据用户提供的内容，填充模板中的各个模块
3. **模块组合** - 从模块库中选择合适的模块，组合成符合需求的页面结构
4. **主题适配** - 自动支持深色/浅色主题切换，颜色系统自动适配
5. **响应式设计** - 自动适配桌面、平板、手机等不同屏幕尺寸

## 核心原则

1. **设计一致性** - 所有页面遵循统一的设计系统（颜色、排版、间距、圆角、阴影、动效），不随意硬编码样式值
2. **内容优先** - 设计服务于内容，不为了炫技牺牲可读性和性能；根据内容类型选择合适的模块组合
3. **渐进增强** - 基础功能必须可用，进阶效果按需添加；始终支持 `prefers-reduced-motion` 减少动画偏好
4. **可访问性** - 文字对比度≥4.5:1，语义化HTML，键盘可导航，焦点状态明显
5. **性能优先** - 控制backdrop-filter使用数量，精简CSS/JS，优化图片，确保页面加载流畅
6. **单文件交付** - 所有CSS/JS内联在单个HTML文件中，无需外部依赖，可直接在浏览器打开

## 工作流程

### 第一步：理解需求

在开始创建网页之前，先明确以下信息：

1. **网页主题** - 这个网页是关于什么的？（学习路线、作品集、产品介绍等）
2. **核心内容** - 用户提供了哪些具体内容需要展示？
3. **页面结构** - 需要哪些章节/模块？大致顺序是什么？
4. **特殊需求** - 是否有特殊的交互效果、数据可视化、功能模块需求？

如果用户提供的信息不足，主动询问关键信息，但不要问太多问题（一次最多2-3个）。

### 第二步：复制模板

将 `assets/template.html` 复制到用户指定的输出位置，作为基础模板。

模板已包含：
- 完整的HTML结构
- CSS变量与深色/浅色主题系统
- 玻璃拟态设计风格
- 导航栏（含主题切换按钮）
- Hero区域（标题+副标题+统计卡片）
- 2个示例章节（卡片网格）
- 页脚
- 滚动进度条
- 滚动入场动画
- 响应式布局
- 减少动画偏好支持

### 第三步：定制内容

根据用户需求，修改模板中的以下部分：

#### 1. 基础信息
- `<title>` - 页面标题
- `<meta name="description">` - 页面描述
- 导航栏Logo和网站名称
- 页脚文字

#### 2. Hero区域
- 主标题（第一行 + 高亮行）
- 副标题描述
- 统计卡片（数字 + 标签，最多4个）

#### 3. 章节内容
根据需要增删章节，每个章节包含：
- 章节标题
- 章节副标题（可选）
- 内容模块（卡片网格、时间线、表格、代码块等）

#### 4. 导航链接
根据实际章节数量和ID，更新导航栏的链接。

### 第四步：选择和组合模块

从 `references/module-library.md` 中选择合适的模块，替换或添加到页面中。

**常用模块组合建议：**

| 网页类型 | 推荐模块组合 |
|----------|-------------|
| 学习路线图 | Hero + 时间线 + 进度条 + 功能卡片 + 表格 + 代码块 |
| 个人作品集 | Hero + 项目卡片网格 + 技能进度条 + 时间线 + 联系表单 |
| 产品介绍 | Hero + 功能卡片 + 截图展示 + 价格表格 + 提示框 + CTA按钮 |
| 知识总结 | Hero + 分类卡片 + 代码块 + 表格 + 引用提示 + 标签徽章 |
| 项目展示 | Hero + 项目卡片 + 技术栈标签 + 时间线 + 代码块 + 截图 |

### 第五步：设计系统一致性检查

参考 `references/design-system.md`，确保：

1. **颜色** - 使用CSS变量，不要硬编码颜色值
2. **间距** - 使用8px基础单位的倍数
3. **圆角** - 使用 `--radius-sm/md/lg` 变量
4. **阴影** - 使用 `--shadow-sm/md/lg` 变量
5. **动效** - 使用 `--ease` 缓动函数，时长符合规范
6. **玻璃效果** - 统一使用 `background: var(--bg-glass); backdrop-filter: var(--glass);`
7. **响应式** - 在768px断点处适配移动端
8. **可访问性** - 支持 `prefers-reduced-motion`，文字对比度达标

### 第六步：验证和交付

1. **在浏览器中打开** - 验证页面渲染正常
2. **检查主题切换** - 深色/浅色主题都正常显示
3. **检查响应式** - 调整窗口大小，验证移动端适配
4. **检查动画** - 滚动入场动画、悬停效果正常
5. **检查内容** - 所有用户提供的内容都正确展示
6. **交付文件** - 通过 `present_files` 交付最终HTML文件

## 进阶效果

如需添加更丰富的交互效果，可参考模块库中的"进阶效果模块"部分：

- **3D Tilt卡片** - 鼠标悬停时卡片3D倾斜+光影效果
- **点击波纹** - 点击页面时产生波纹扩散动画
- **数字计数动画** - 数字从0滚动到目标值
- **粒子背景** - Canvas粒子漂浮+连线效果
- **滚动视差** - 背景与内容不同速度滚动
- **打字机效果** - 文字逐字显示动画

**注意**：进阶效果会增加页面复杂度和性能消耗，根据实际需求选择性添加，不要为了炫技而影响页面性能和可读性。

## 性能优化建议

1. **backdrop-filter** - 大量玻璃卡片时，考虑将 `blur(24px)` 降低到 `blur(16px)`
2. **动画数量** - 不要给所有元素都添加入场动画，只给关键模块添加
3. **图片优化** - 背景图片使用压缩后的格式，避免过大的文件
4. **CSS精简** - 移除未使用的模块CSS
5. **JS精简** - 只保留需要的交互功能代码

## 输出规范

### 输出格式
- **文件格式**：单个 `.html` 文件，UTF-8编码，包含内联CSS和JavaScript
- **文件命名**：根据网页主题命名，如 `学习路线图.html`、`个人作品集.html`
- **交付方式**：通过 `present_files` 工具交付，附带简短说明

### 质量检查清单

交付前必须逐项验证：

- [ ] **基础结构** - HTML结构完整，有 `<!DOCTYPE html>`、`<head>`、`<body>`
- [ ] **元数据** - `<title>` 和 `<meta name="description">` 已填写
- [ ] **主题切换** - 深色/浅色主题切换功能正常，颜色系统自动适配
- [ ] **响应式** - 桌面（>1024px）、平板（768-1024px）、手机（<768px）均正常显示
- [ ] **玻璃效果** - 卡片使用统一的 `var(--bg-glass)` 和 `var(--glass)`，视觉一致
- [ ] **入场动画** - 滚动入场动画正常，支持 `prefers-reduced-motion` 降级
- [ ] **滚动进度** - 顶部滚动进度条正常工作
- [ ] **导航功能** - 导航栏链接可正常跳转，锚点定位准确
- [ ] **内容完整** - 所有用户提供的内容已正确填充，无遗漏
- [ ] **无控制台错误** - 浏览器控制台无JavaScript错误
- [ ] **性能可接受** - 页面加载流畅，无明显卡顿，backdrop-filter数量合理

### 禁止事项
- ❌ 禁止硬编码颜色值，必须使用CSS变量
- ❌ 禁止使用外部CDN依赖，所有资源必须内联
- ❌ 禁止添加用户未要求的复杂交互效果
- ❌ 禁止破坏 `prefers-reduced-motion` 支持
- ❌ 禁止交付未经验证的页面

## 常见问题

**Q: 用户没有提供具体内容怎么办？**
A: 先创建基础结构，使用占位文字（如"待补充"），并告知用户需要提供哪些内容。

**Q: 可以创建多页网站吗？**
A: 本Skill专注于单页HTML网站。多页网站可以创建多个HTML文件，共享相同的CSS和设计系统。

**Q: 可以添加后端功能吗？**
A: 本Skill生成纯前端静态HTML页面。如需后端功能，建议用户使用专门的全栈开发工具。

**Q: 页面加载慢怎么办？**
A: 检查是否添加了过多进阶效果，减少backdrop-filter的使用，优化图片大小。
