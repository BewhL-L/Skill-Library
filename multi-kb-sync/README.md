# 多知识库同步与联动

> 多知识库同步与联动助手。管理和同步多个 Obsidian 知识库之间的标签体系、模板、样式、配置，确保跨知识库的一致性和可联动性。当用户有多个知识库、需要统一标签体系、要求同步模板/样式/配置、需要跨知识库引用、或询问"多个知识库怎么管理"时使用。支持标签同步、模板同步、CSS 样式同步、Dataview 查询同步、Templater 脚本同步。生成同步报告和冲突处理方案。

---

## 功能特性

### 核心原则

- **全局标准优先**：全局标签集、模板、样式为权威标准，各知识库必须对齐
- **增量同步**：只同步变更的部分，不覆盖各知识库的本地自定义内容
- **冲突可追溯**：同步前检测冲突，冲突处理有记录，可回滚
- **本地扩展允许**：各知识库可在全局标准基础上扩展，但不得修改核心字段和全局标签
- **自动化优先**：同步操作尽量自动化，减少人工操作，降低出错概率
