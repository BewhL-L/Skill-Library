# 系统设计方案生成器

> 系统设计方案生成器。为高并发/高可用/分布式系统生成完整设计方案，包含需求分析、容量评估、架构设计、技术选型、核心流程、数据模型、接口设计、异常处理、扩展性、可观测性。当用户需要设计系统、要求生成架构方案、询问"XX系统怎么设计"、需要高并发/高可用方案、或准备系统设计面试时使用。支持电商秒杀、社交Feed、即时通讯、在线支付、RAG系统、微服务架构、内容分发等典型场景。生成的方案包含架构图描述、容量估算、技术选型理由和 trade-off 分析。

---

## 功能特性

### 核心原则

- **需求驱动**：先明确功能需求和非功能需求（QPS、延迟、可用性、数据量），再设计方案
- **容量评估**：所有设计决策基于量化的容量估算（用户量、QPS、存储、带宽），不是拍脑袋
- **分层设计**：接入层 → 应用层 → 服务层 → 数据层 → 基础设施层，层层清晰
- **trade-off 分析**：每个技术选型都说明优势、劣势、为什么选这个、替代方案是什么
- **可演进**：方案支持从简单到复杂的演进（单体 → 微服务 → 分布式），不一步到位过度设计
