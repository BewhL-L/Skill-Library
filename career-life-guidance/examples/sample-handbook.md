# 写在前面

> 这是一份示例手册，展示 career-life-guidance Skill 的产出格式和写作风格。完整手册通常5-20万字，本示例为精简版。

你好，我是一个走过这条路的人。

我见过太多普通一本的计算机学生，在大三的时候陷入迷茫：考研还是就业？前端还是后端？去大厂还是去中小公司？每天刷着知乎和B站，看了无数"过来人"的经验，却越来越不知道自己该做什么。

我写这份手册，不是要告诉你"标准答案"——因为根本没有标准答案。我要做的，是帮你建立一套**自己做决策的框架**，然后给你一条**可以照着执行的路线**。

这份手册不会告诉你"你必须..."，而是会告诉你"以我的经验，我建议你..."，然后把为什么、怎么做、不做的后果都讲清楚。

**使用建议**：
- 第一遍：通读，建立全局认知
- 第二遍：重点读第三篇（项目实战），开始动手做项目
- 第三遍：根据自己的情况，调整学习计划和求职策略
- 每完成一个阶段，回到对应章节检查进度

# 第一篇：决策与方向

## 1.1 我是谁

### 身份画像

| 字段 | 内容 |
|------|------|
| 学历背景 | 普通一本，计算机科学与技术专业，大三 |
| 当前阶段 | 在校，无实习经历，成绩中等（专业排名30%） |
| 工作经验 | 0年，仅有课程作业和小项目 |
| 年龄 | 21岁 |
| 所在城市 | 新一线城市，有一定互联网产业 |
| 目标设定 | 毕业时月薪12-15k，去互联网公司做开发 |
| 约束条件 | 家庭条件一般，无法支撑考研二战，需要尽快就业 |
| 偏好倾向 | 喜欢做能看到效果的东西，对前端感兴趣，数学一般 |

### 能力盘点

**优势**：
- 计算机科班出身，有一定基础
- 年轻，学习能力强，试错成本低
- 对前端有兴趣，有内在动力
- 所在城市有互联网产业，就业机会较多

**劣势**：
- 普通一本，学历在求职时不占优势
- 无实习经历，简历空白
- 成绩中等，没有奖学金等亮点
- 数学一般，不适合走算法/AI研究路线
- 家庭条件一般，经济压力较大

### 优劣势分析

以我的经验，普通一本计算机学生的核心问题不是"学不会"，而是**不知道学什么才能找到工作**。学校教的课程和企业需要的能力之间有巨大的gap，很多人到了大四才发现自己什么都不会。

你的优势是年轻、有兴趣、所在城市有机会。你的劣势是学历不占优、无实习、成绩一般。这意味着你**不能和985/211的学生拼学历和成绩**，你必须拼**项目经验和实战能力**。

**不做的后果**：如果继续按学校的节奏走，到大四找工作时，你会发现自己的简历上只有"熟练掌握C语言"、"了解数据结构"这种空话，而HR想看的是"做过什么项目、用了什么技术、解决了什么问题"。到时候你要么去小公司拿很低的工资，要么被迫考研二战，而你的家庭条件不允许你二战。

## 1.2 我要去哪

### 目标设定

**短期目标（1年内）**：
- 完成3个完整的前端项目（入门+进阶+高级）
- 找到一份前端开发实习（月薪5-8k）
- 毕业时拿到前端开发offer（月薪12-15k）

**中期目标（3年内）**：
- 成为中级前端工程师，能独立负责中型项目
- 月薪达到20-25k
- 建立个人技术博客，积累行业人脉

**长期目标（5-10年）**：
- 成为高级前端工程师或前端架构师
- 月薪达到30-40k，或转向技术管理
- 有一定的副业收入和理财积累

### 赛道选择：前端 vs 后端 vs 其他

| 维度 | 前端 | 后端 | 测试 | 运维 |
|------|------|------|------|------|
| 入门难度 | 低（能看到效果，有正反馈） | 中（需要理解系统设计） | 低 | 中 |
| 学历要求 | 中（更看重项目和作品） | 高（大厂更看重学历和基础） | 低 | 中 |
| 薪资水平 | 中高（1-3年15-25k） | 高（1-3年18-30k） | 中（1-3年10-18k） | 中高（1-3年12-22k） |
| 就业机会 | 多（每个公司都需要前端） | 多 | 中 | 中 |
| 适合你吗 | ✅ 非常适合（有兴趣、能看到效果、学历要求相对低） | ⚠️ 可以但不最优（学历不占优、数学一般） | ❌ 不建议（天花板低、容易被替代） | ❌ 不建议（需要熬夜、兴趣不匹配） |

**我的建议**：主攻前端。

**为什么**：
1. 你对前端有兴趣，兴趣是最好的老师，能让你坚持下去
2. 前端能快速看到效果，写几行代码就能在浏览器里看到变化，正反馈强，不容易放弃
3. 前端对学历的要求相对较低，更看重项目作品和实战能力，这正好弥补了你普通一本的劣势
4. 前端就业机会多，每个互联网公司都需要前端，中小公司也有大量需求
5. 你数学一般，不适合走后端的算法/系统优化路线，也不适合走AI研究路线

**怎么做**：
1. 第1-2个月：HTML/CSS/JavaScript基础，完成1个静态网页项目
2. 第3-4个月：Vue/React框架，完成1个动态Web应用
3. 第5-8个月：深入前端工程化，完成1个全栈项目（前端+Node.js后端）
4. 第9个月：准备简历和面试，开始投实习
5. 第10-12个月：实习+秋招，拿到正式offer

**不做的后果**：如果选择后端，你需要和大量985/211的学生竞争，他们的学历和计算机基础比你好，你在简历筛选阶段就容易被刷掉。如果选择测试，虽然入门容易，但天花板低，3年后薪资和发展都会受限，而且测试岗位正在被自动化测试和AI测试替代。

# 第三篇：项目与实战（示例精简，完整版占全书25%-35%）

## 3.1 项目一：个人博客静态页面（入门级）

### 项目背景
这是你的第一个项目，目标是验证HTML/CSS/JavaScript基础学习成果，同时作为你未来技术博客的载体。

### 功能清单
- [x] 首页：文章列表、分页、分类标签
- [x] 文章详情页：Markdown渲染、目录、阅读进度
- [x] 关于页：个人介绍、技能展示、联系方式
- [x] 响应式设计：适配手机、平板、桌面
- [x] 暗色模式：一键切换深浅主题

### 技术栈
- HTML5 + CSS3 + 原生JavaScript（ES6+）
- Marked.js（Markdown渲染）
- 无框架，纯原生实现

### 实现要点
1. 使用CSS Grid和Flexbox布局
2. 使用localStorage存储主题偏好
3. 使用Intersection Observer实现滚动动画
4. 语义化HTML，SEO友好

### 简历描述模板
> **个人博客系统** | 独立开发 | 2026.03-2026.04
> - 基于原生HTML/CSS/JavaScript开发的个人技术博客，支持Markdown文章渲染、分类标签、暗色模式
> - 使用CSS Grid/Flexbox实现响应式布局，适配手机/平板/桌面三端
> - 使用Intersection Observer API实现滚动入场动画，首屏加载时间<1s
> - 项目已部署到GitHub Pages，累计访问量XXX次

# 第四篇：求职与入职（示例精简）

## 4.1 简历优化要点

**普通一本学生的简历策略**：
1. 把"项目经历"放在"教育背景"前面，用项目弥补学历劣势
2. 每个项目用STAR法则描述：情境(Situation)、任务(Task)、行动(Action)、结果(Result)
3. 量化结果：用数字说话，如"首屏加载时间<1s"、"用户量XXX"
4. 技术栈关键词：匹配JD中的技术要求，通过ATS筛选

# 第六篇：支撑与风险（示例精简）

## 6.1 身体健康

**程序员的身体管理**：
- 每写代码45分钟，站起来活动5分钟
- 每天至少30分钟有氧运动（跑步/游泳/健身）
- 每年体检一次，重点检查颈椎、腰椎、视力、肝功能
- 不要熬夜，23点前睡觉，保证7-8小时睡眠
