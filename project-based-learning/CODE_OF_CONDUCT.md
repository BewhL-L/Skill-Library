# CODE_OF_CONDUCT

## 适用范围

本项目是个人使用的技能包，不接收外部贡献，也不承载社区互动。本文件只声明使用边界。

## 使用边界

1. 仅用于为自己规划学习项目；
2. 生成的方案若基于他人项目或代码，遵守原项目许可；
3. 不把方案中的企业内网信息、真实业务数据外传（见 `SECURITY.md`）。

## 内容准则

- 方案中的技术判断允许有倾向，但必须给理由；
- 不生成鼓励抄袭、绕过授权、攻击他人系统的内容；
- 涉及竞品/他人的技术方案时，如实标注来源，不冒充原创。

## 参考

社区行为准则参考 [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)。本项目不设执行委员会。
