# 速查表生成器

> 从知识库中提取**高频核心知识点**，生成**一页纸速查表**，用于快速查阅和考前复习。

---

## 核心原则

1. **一页纸原则**：速查表控制在 1-2 页 A4 纸内，信息密度高但不拥挤
2. **高频优先**：只收录最常用、最容易忘、面试最常考的知识点，不追求全面
3. **结构化**：使用表格、列表、分栏等结构化方式，便于快速定位
4. **可打印**：Markdown 格式，支持直接打印为 PDF，排版适合 A4 纸
5. **知识联动**：每个知识点标注对应知识库笔记链接，需要深入时可跳转

---

## 速查表类型

> 5 种类型的详细模板、各技术栈推荐速查表清单、质量检查清单详见 [references/cheatsheet-types.md](references/cheatsheet-types.md)，生成时按对应类型的模板执行。

| 类型 | 适用场景 | 核心格式 |
|------|---------|---------|
| 命令速查表 | Git/Docker/Linux/npm/kubectl | 命令+说明+示例表格，常用组合 |
| API/方法速查表 | Vue3 API/Array方法/Spring注解 | API+说明+示例+返回值表格 |
| 概念对比速查表 | var/let/const、深/浅拷贝 | 多维度对比表格+选择建议 |
| 架构/流程速查表 | 请求流程、部署流程 | 编号流程+组件职责表+常见问题 |
| 面试高频题速查表 | 面试前复习 | 题目+核心要点+关键词 |

## 使用示例

**输入**："生成一份 Git 常用命令速查表，要适合打印，包含日常开发 90% 的场景"

**输出**：
- 一页 A4 可打印的速查表（分类清晰、信息密度高）
- 分类：基础操作、分支管理、远程操作、撤销与回退、暂存与储藏、查看历史、冲突解决、高级技巧
- 每个命令：命令语法、说明、常用参数、示例
- 常见错误和注意事项（⚠️ 标注）
- 速查索引（按场景快速定位）
- 与 `[[Git]]` `[[版本控制]]` 等知识库笔记双向链接

## 工作流程

### 步骤1：确认速查表类型和主题

- 类型：命令 / API / 概念对比 / 架构流程 / 面试高频题
- 主题：具体技术领域（如 Git、Vue3 API、Java 面试题）
- 范围：从知识库提取 / 通用知识生成
- 格式：一页纸精简 / 详细版

### 步骤2：从知识库提取核心知识点

- 扫描知识库中相关分类的笔记
- 提取高频出现的概念、命令、API
- 按逻辑分组（如基础操作/分支操作/远程操作）
- 每个知识点标注对应笔记链接

### 步骤3：按类型模板生成速查表

- 使用表格为主，列表为辅
- 控制在 1-2 页 A4 纸内
- 信息密度高但不拥挤
- 添加注意事项和常用组合

### 步骤4：添加知识联动

- 底部添加"深入学习"链接，指向知识库对应笔记
- 高频概念添加 `[[]]` 双链

### 步骤5：生成 Frontmatter（如保存到知识库）

```yaml
---
title: XXX 速查表
tags: [速查表, 技术栈, 复习]
category: 对应分类
created: 2026-08-31
updated: 2026-08-31
difficulty: ⭐⭐
status: ✅ 内容已完善
priority: 重要
type: 速查表
---
```

## 排版规范（适合打印）

1. 使用三级标题（`###`）分组，不使用二级以上大标题
2. 表格为主，每个表格不超过 8 行，超过则拆分
3. 代码块使用短代码（单行或 2-3 行），不使用长代码
4. 重要提示使用 `>` 引用块
5. 整体控制在 1500-2500 字（一页 A4 约 1500 字）
6. 列数控制在 3-4 列，超过则信息过密

---

## 输出规范

1. 速查表必须一页可打印（A4 纵向或横向），内容精炼，不冗余
2. 所有命令、代码、配置必须准确可直接复制使用，无占位符
3. 分类清晰，使用表格或分栏布局，信息密度高但不拥挤
4. 每个条目有简短说明（不超过 2 行），关键参数标注默认值和可选值
5. 常见错误和注意事项用醒目标注（如 ⚠️、❌）
6. 速查表类型与内容匹配（命令速查用表格，概念速查用思维导图式布局）
7. 所有技术概念添加 `[[]]` 双链，与知识库关联
8. 排版适合打印（黑白可读、字号不小于 9pt、边距合理）
9. 有明确的标题、版本、日期、适用版本范围
10. 复杂操作有步骤编号，简单命令用表格罗列

## 质量检查清单

- [ ] 速查表类型明确，主题聚焦
- [ ] 内容为高频核心知识点，无冷门内容
- [ ] 以表格为主，结构清晰，便于快速定位
- [ ] 控制在 1-2 页 A4 纸内（1500-2500 字）
- [ ] 每个知识点准确无误（命令/API/概念）
- [ ] 有注意事项或常见坑提示
- [ ] 底部有深入学习的知识库链接
- [ ] 如保存到知识库，Frontmatter 完整
- [ ] 排版适合打印（表格不过宽、代码不过长）

## 与其他 Skill 的协作

- **与 `obsidian-knowledge-base-creator` 协作**：从知识库笔记中提取知识点，速查表保存为知识库笔记，用 `validate` 校验
- **与 `knowledge-review-spaced` 协作**：复习时可用速查表快速回顾，速查表可作为复习材料
- **与 `learning-path-planner` 协作**：学习路线每阶段结束时，生成该阶段的速查表用于复习
- **与 `tech-concept-deep-dive` 协作**：速查表中的概念需要深入理解时，用深度拆解器生成完整笔记
