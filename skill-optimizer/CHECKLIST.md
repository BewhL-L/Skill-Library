| 优先级 | 项数 | 每项分值 | 总分 |

| **合计** | **101** | - | **160.5 分** |

### 等级划分

| 完成度 | 等级 | 状态 |
|--------|------|------|
| ≥90% | S | 🏆 专业级 |
| 80-89% | A | ✅ 优秀 |
| 70-79% | B | ⚠️ 良好 |
| 60-69% | C | ❌ 一般 |
| <60% | D | 🔴 较差 |

### 快速评估

```bash
# 自动评估
python skill-opt.py audit --path ./my-skill

# 手动评估
# 1. 统计已完成的 P0 项数
# 2. 统计已完成的 P1 项数
# 3. 按公式计算：(P0完成*3 + P1完成*2 + P2完成*1 + P3完成*0.5) / 160.5 * 100
```
