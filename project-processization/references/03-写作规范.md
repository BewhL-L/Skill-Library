# 写作规范（标准化 Markdown / Frontmatter / Obsidian）

> 本 Skill 产物是"项目 README + 学习指南"，需同时在 GitHub、Obsidian、Typora 正常渲染。
> 以下规范同时是 `validate_md.py` 的校验依据。

## 1. Frontmatter

文件以 `---` 开始、以 `---` 结束，字段示例：

```yaml
---
title: 企业智能知识库助手 · 学习指南
category: 项目实战
tags:
  - AI应用开发
  - RAG
  - 全栈
difficulty: expert
created: 2026-10-12
updated: 2026-10-14
status: 学习指南
version: v1.0
tech_stack: [Python, FastAPI, Vue3, TypeScript, LangChain, RAG, Agent]
source: AI 生成项目 + 人工学习指南
---
```

- Frontmatter 内**禁止出现 ``` 围栏**，否则会破坏解析。
- 标签用列表，避免逗号字符串；日期统一 `YYYY-MM-DD`。

## 2. 标题层级

- 全文**恰好 1 个 H1**（项目名），原文 README 已有的 H1 不要重复新增。
- 层级不得跳跃：H1 后直接 H3 即错误；H3 之后直接 H5 即错误。
- 学习指南本体用 H2（如 `## 🎓 从零到专家：完整学习指南`），八章用 H3，小节用 H4。
- 一般不使用 H5/H6；内容再深就用列表或表格。

## 3. 代码围栏

- 成对使用 ```，围栏总数必须为偶数；文档结束前不得悬空。
- 标注语言（`bash`/`python`/`yaml`/`json`/`mermaid`）；命令与注释分行写。
- 围栏内的 `#` 是注释，不是标题——这正是校验必须用"围栏状态机"的原因。

## 4. 表格

- 每个表格的表头、分隔行、数据行列数必须一致。
- 单元格内若出现竖线，转义为 `\|`；双链内的 `|` 也要转义。
- 分隔行示例（3 列）：`|------|------|------|`。
- 长文本优先用表格做"对比/清单"，但不要把连续步骤硬塞进表格。

## 5. Obsidian callout

折叠提示块语法：

```markdown
> [!tip] 控制评测花费
> - 调试时先 3-5 条用例 + `--no-judge`
> - Embedding 缓存默认开启，不重复计费

> [!warning] 裸跑与 Docker 配置不同
> 裸跑默认 SQLite + Chroma，Docker 才用 PostgreSQL + Qdrant。

> [!abstract] 基础不牢？先补这些
> | 不熟的 | 补到什么程度 |
> |---|---|
```

常用类型：`note / tip / warning / danger / info / abstract / checklist / success / question`。

## 6. Mermaid 图

- 用 ` ```mermaid ` 围栏；流程图优先 `flowchart TD`，分工图用 `graph`。
- 节点文字含括号/冒号时用引号包起来，如 `A["AI：搭骨架"]`。
- 箭头标签用 `-- 文字 -->`；避免在节点文字里直接写未转义的特殊字符。

## 7. 双链与锚点

- Obsidian 双链：`[[目标页]]` 或 `[[目标页|显示文字]]`；禁止目标为空的写法（左方括号后直接跟竖线、缺少目标页）。
- 同文档跳转用标准 Markdown 链接：`[文字](#锚点)`。
- GitHub 锚点规则（由 `make_toc.py` 自动生成，勿手算）：
  1. 转小写；2. 移除标点（保留字母/数字/中文/空白/连字符）；3. 每个空白转一个连字符。
  - 注意：连续空格不合并，`a + b` 生成 `a--b`。
- 跨节引用要可验证：正文写"见 5.4"时，5.4 小节必须真实存在。

## 8. 语言与风格

- 与项目/用户语言一致，默认简体中文；命令、路径、标识符保持英文原文。
- 命令必须可照抄：写清"在哪个目录、前置条件、输出位置、失败现象与排查"。
- 数字给口径（物理行、是否含 `__init__.py`、是否排除缓存）；易变内容写"系列/约数"。
- 每章动作导向：多用"做什么 → 为什么 → 怎么做 → 如何验证"；少用空泛形容。
- 敏感信息一律脱敏；不把"正确的废话"当结论（要可执行、可检验）。

## 自检（与 validate_md 对应）

- [ ] Frontmatter 以 `---` 开始并正确闭合，无围栏
- [ ] 恰好 1 个 H1；无层级跳跃；无 H5/H6
- [ ] 代码围栏成对、标注语言
- [ ] 表格列数一致；单元格竖线已转义
- [ ] 无目标为空的双链（左方括号后直接跟竖线）
- [ ] 锚点链接由 `make_toc.py` 生成并与标题一致
