# 笔记质量评估器

> AI驱动的 Obsidian 笔记质量评估器。对知识库中的笔记进行内容质量评估，检查内容深度、准确性、完整性、结构规范性，给出具体的改进建议和优先级排序。与 obsidian-knowledge-base-creator 的结构校验（validate）不同，本 skill 评估的是内容质量而非结构合规。当用户需要检查笔记质量、要求改进笔记内容、需要批量评估知识库、或询问"这篇笔记写得怎么样"时使用。支持单篇笔记深度评估和批量笔记快速评估两种模式。

---

## 功能特性

### 核心原则

- **内容优先**：评估的是内容质量（深度、准确性、完整性），不是格式合规（格式由 `obsidian-knowledge-base-creator` 的 `validate` 负责）
- **具体可执行**：每个问题都给出具体的改进建议和示例，不是模糊的"建议加深"
- **优先级排序**：按问题严重程度排序（严重 > 重要 > 建议），先改影响最大的
- **差异化标准**：不同难度的笔记有不同的质量标准（入门笔记不要求源码级分析）
- **非破坏性**：只生成评估报告和改进建议，不自动修改笔记内容
