# AI 协作 Prompt 库（复制即用）

> 指南里教学习者"如何利用 AI"，本文件提供可直接复制的 Prompt。所有 Prompt 都遵循一个
> 目标：让 AI 当"老师/陪练"，而不是"替身"。涉及核心原理时，要求 AI 按"作用 → 底层原理 →
> 用法要点"三位一体回答，拒绝只给结论。

## 目录

1. 让 AI 讲代码（精读）
2. 三位一体拆解核心概念
3. 生成"我是小白"追问
4. 让 AI 出白板题 / 默写检查
5. 帮你起草 golden QA
6. 排查报错（不直接让 AI 改）
7. 复现算法的"先自测再对照"
8. 评测结果归因
9. 红线：这些不能让 AI 替你做

---

## 1. 让 AI 讲代码（精读）

```text
你是资深 RAG/全栈工程师，我在学习一个 AI 生成的项目。请阅读文件 <路径/粘贴代码>，
只做讲解，不要替我改写。按以下结构输出：
1. 这个文件在系统里处于什么位置、解决什么问题（结合整体架构）；
2. 核心函数逐个讲：输入是什么、输出是什么、关键步骤为什么这么做；
3. 用一段大白话讲清数据流（从请求到返回）；
4. 指出 3 个我必须看懂的关键行，并说明为什么；
5. 出 3 道思考题考我（先别给答案）。
讲解时假设我只会基础 Python，用到的每个专业词都先用一句话解释。
```

## 2. 三位一体拆解核心概念

```text
请按"三位一体"拆解 <概念，如 RRF 倒数排名融合 / ReAct / 父子分块 / Rerank>：
1. 作用：它解决什么问题，没有它会怎样；
2. 底层原理：核心逻辑/公式，配合一个可手算的最小例子（给出具体数字）；
3. 用法要点：在本项目里是哪段代码、关键参数、常见坑。
最后给一个"如果面试官问起，30 秒怎么回答"。
```

## 3. 生成"我是小白"追问

```text
我刚听完你的解释，现在我是零基础小白。请围绕上一条内容，连续提出 5 个
"最容易卡住的基础问题"，并逐个用生活化类比回答。不要跳步，不要默认我懂前置知识。
```

## 4. 让 AI 出白板题 / 默写检查

```text
请围绕 <算法/流程，如混合检索 RRF 融合> 出一道白板默写题：
- 只给函数签名和输入输出示例，让我手写实现；
- 同时给 3 个边界用例（空列表、并列名次、topK 截断）；
- 我提交后，你先不要直接给答案，而是指出我思路哪里有问题，让我自己改。
```

## 5. 帮你起草 golden QA（你必须人工审核）

```text
请基于这几篇我上传的文档，起草 10 条 RAG 评测用例，覆盖：
事实型、细节型、跨文档综合、关键词精确匹配、反事实"找不到"、多跳推理 各若干。
每条严格输出 JSON 字段：
id, kb_id, category, question, reference_answer,
must_contain_keywords[], expected_document_names[]。
问题要像真实用户问的，不要直接照抄文档标题。
我会逐条审核、改写、补到 40-50 条，你只负责初稿。
```

## 6. 排查报错（不直接让 AI 改）

```text
我在 <操作> 时遇到报错，下面是完整错误堆栈和我的环境（版本、Docker/裸跑、命令）。
请：
1. 先解释这个错误"是什么意思"，指出最可能的根因（按概率排序）；
2. 给我验证根因的命令，让我自己确认；
3. 再给修复步骤，说明每步为什么有效；
4. 说明如何避免复发。
不要直接帮我重写大段代码，我要自己改。
```

## 7. 复现算法的"先自测再对照"

```text
我准备白板手写 <算法>。在我写之前，先别给我代码，只告诉我：
- 输入输出约定、必须满足的性质、2 个典型样例；
- 我写完贴给你后，再对比项目源码，指出我与源码在边界处理、复杂度、命名上的差异。
```

## 8. 评测结果归因

```text
这是我两次评测的指标（粘贴 Hit@K/MRR/Context Precision/忠实度）。
变量只有一个：我把 Rerank 从 true 改成 false。
请：
1. 只基于数据告诉我哪些指标显著变化、可能的机理；
2. 提醒我哪些结论可能是样本太少造成的误判；
3. 建议下一个单变量实验，不要一次改多个变量。
```

## 9. 红线：这些不能让 AI 替你做

- 不要让 AI 替你白板默写核心算法、替你答"为什么这么选型"。
- 不要让 AI 直接生成整份评测报告并当作自己的结论——先自己读数据。
- 不要让 AI 一次性改多个变量/大段重写，导致无法归因、无法回滚。
- 不要在没看懂的情况下接受 AI 的"修复"——先让它给验证命令和原理。
- 任何包含真实密钥/生产数据的内容，不要直接贴给外部模型（先脱敏）。

> 用 AI 的正确姿势：**让它讲、让它问、让它出题、让它挑错；理解和动手留给自己。**
