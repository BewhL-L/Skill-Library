## 4. 卡片 3D tilt（鼠标跟随倾斜）

```css
.glass{transform-style:preserve-3d;transition:transform .25s var(--ease)}
```
```js
card.addEventListener("mousemove",e=>{
  const r=card.getBoundingClientRect();
  const x=(e.clientX-r.left)/r.width-.5, y=(e.clientY-r.top)/r.height-.5;
  card.style.transform=`perspective(900px) rotateY(${x*6}deg) rotateX(${-y*6}deg) translateZ(4px)`;
});
card.addEventListener("mouseleave",()=>card.style.transform="");
```

## 5. 入场 3D 翻入

```css
.rv{opacity:0;transform:perspective(900px) translateY(20px) rotateX(5deg);transition:opacity .8s,transform .8s}
.rv.in{opacity:1;transform:perspective(900px) translateY(0) rotateX(0)}
```
800ms 兜底加 `.in`。

## 7. 模块位置

- wrap：max-width 960px 居中
- 顺序：顶部栏（brand+主题）→ hero 卡（标题+总进度条）→ 3 统计卡 → 阶段进度 → 折线图（带周切换）→ 今日任务 → N 周全景网格

## 9. 动态模块入场规范

dev-strip（落后提示条）等运行时才显示的模块：

- 初始 `hidden`，落后时 `hidden=false`
- 必须加入统一入场队列（pendReveal 或 GSAP groups），和其他卡片同步渐入
- **禁止**初始化时手动 `classList.add("in")`，否则会和其他模块不同步
- **禁止**给动态模块加 `backdrop-filter: blur()`，叠在动态极光背景上会 GPU 卡顿
- 背景用 `var(--glass-tint-strong)` + `var(--glass-border)`，和其他卡片一致
- 图标/按钮可用 `--accent` 色保留警示感，但卡片背景不单独上色
