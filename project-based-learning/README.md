# 项目驱动学习生成器

> 项目驱动学习方案生成器。为全栈+AI工程化学习生成贯穿多个技术点的综合实战项目方案，包含完整需求文档、技术选型理由、架构设计、分步实现教程（每步对应知识库笔记）、验收标准和扩展方向。当用户需要通过项目整合知识点、要求生成实战项目方案、询问"做什么项目能练XX技术"、或需要从0到1的项目学习指南时使用。支持全栈应用、微服务系统、AI应用（RAG/Agent/多模态）、前端工程化项目等类型。生成的项目方案与 Obsidian 知识库笔记深度联动。

---

## 功能特性

### 核心原则

- **完整闭环**：项目方案覆盖需求→设计→实现→测试→部署→优化的完整流程
- **知识联动**：每一步实现标注对应的知识库笔记，项目完成后知识点也复习完毕
- **可交付**：项目有明确的验收标准和可演示的最终产物，不是半成品
- **梯度递进**：项目分阶段实现，每阶段有独立可运行的产物和验收点
- **生产规范**：代码结构、命名、注释、错误处理符合生产环境标准，不是玩具代码
