# 数据驱动替换清单

## 必替换项（grep 定位）

```powershell
# 在原文件副本上 grep，拿到实际字符串
Grep -n "const START|const END|const PHASES|const BASE_PLAN|todayPos|<title>|<h1>|pl-node|localStorage.getItem" 文件.html
```

| 项 | 原文件典型值 | 替换为 | 注意 |
|----|------------|--------|------|
| START | `new Date(2026,8,28)` | `new Date(2026,9,12)` | 月从 0 开始，10 月 = 9 |
| END | `new Date(2027,5,1)` | `new Date(2027,3,30)` | 4 月 = 3 |
| PHASES | `{1:"阶段一 · 基础补熟",...}` | 新阶段名 | 7 个 key 对应 7 个 ph 值 |
| BASE_PLAN | `[{w:1,ph:1,t:"...",days:[...]},...]` | 新周数组 | 每周 7 天，每天 [["任务",小时]] |
| todayPos | `Math.min(34,...) diff<245` | `Math.min(28,...) diff<203` | 周数-1 和总天数 |
| localStorage | `"focus35-v1"` | `"ragstudy-v1"` | 同时改 notes/links/schema |

## 常见 MISS 原因

1. **品牌文字猜错**：原文件可能是 `FOCUS·35` 不是 `RAG+Agent`，先 grep 再写匹配串
2. **日期格式不同**：`06·01` vs `06-01` vs `2027-06-01`，看原文件实际
3. **PHASES 文案不同**：可能是"阶段一·基础补熟"不是"阶段0·环境"
4. **pl-node 结构**：`<span class="pl-node"><b>06·01</b></span>` 可能有 aria-hidden

## Python 替换模板

```python
import io
p = r"副本.html"
s = io.open(p, encoding="utf-8").read()
reps = [
    ('旧字符串1', '新字符串1'),
    ('旧字符串2', '新字符串2'),
]
for a,b in reps:
    if a in s:
        s = s.replace(a,b); print("OK:", a[:40])
    else:
        print("MISS:", a[:40])
io.open(p,"w",encoding="utf-8").write(s)
```

## BASE_PLAN 结构

```js
const BASE_PLAN = [
  {w:1, ph:1, t:"阶段标题", days:[
    [["任务1",2],["任务2",3]],  // 周一
    [["任务3",8]],               // 周二
    // ... 周三到周六
    [["复习卡片",0.3],["复盘",1.5],["缓冲",2.2]]  // 周日（4h）
  ]},
  // ... 更多周
];
```

- 工作日每天 8h（多个任务凑满）
- 周日 4h（卡片+复盘+缓冲）
- ph 值对应 PHASES 的 key
