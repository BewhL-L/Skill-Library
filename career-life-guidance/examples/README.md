# 示例项目

本目录包含使用 career-life-guidance Skill 生成的示例手册，展示成品的格式、结构和写作风格。

## 示例列表

| 示例 | 文件 | 类型 | 说明 |
|------|------|------|------|
| 普通一本计算机学生职业指导手册 | `sample-handbook.md` | 完整版示例（精简） | 展示六篇结构、前辈语气、项目实战、固定套件 |

## 如何使用示例

1. **查看成品格式**：打开示例文件，查看完整的六篇结构和固定套件
2. **学习写作风格**：参考"前辈语气"的表达方式，有温度但不鸡汤
3. **理解项目实战**：查看第三篇项目实战的完整度标准（需求→技术→实现→简历包装）
4. **复制模板**：将示例作为模板，根据用户的具体身份和需求修改内容

## 示例特点

每个示例都展示了：
- 完整的六篇人生时间线结构（决策→学习→项目→求职→发展→支撑）
- 成品固定套件（写在前面、能力总览、篇小结、收尾套件、文档信息）
- "前辈语气"写作风格（有温度、可执行、不说教）
- 每个建议包含"为什么+怎么做+不做后果"三要素
- 项目实战的完整实现指南和简历包装模板
- Obsidian标准化格式（Frontmatter、双链、表格）
