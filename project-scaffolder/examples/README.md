## 示例 1：PetShare 宠物社交平台（真实案例）

**项目类型**：软件/技术 + 社交（混合型）

**用户请求**：
> 我想做一个宠物爱好者社交平台，爱好者注册账号，互相交流关注，发布宠物日常照片，最终做出小程序或可上线的 app。

**生成产出**：
- 后端：FastAPI + SQLAlchemy + JWT + WebSocket（9模型/8路由/16测试）
- 前端：微信小程序（12页面）
- 文档：《项目全景总结与行动指南》（2500+ 行，三篇递进 16 章）
- Git：7 次提交

**项目路径**：`<你的工作区>/pet-social-app`（示例路径）

**关键亮点**：
- 功能完整性：P0-P3 全部优化（宠物档案/收藏/搜索/评论点赞/通知）
- 技术深度：WebSocket 实时私信 + 推荐算法 + Redis 缓存
- 工程化：Docker + CI/CD + pytest 测试套件
- 求职导向：20 道面试题 + 七要素深度讲解
